【任务 T5·PythonShell 并发命令结果错配/丢失】
Agent 的 Python 执行壳支持并发提交命令。实测发现：同时提交两个命令时， 其中一个命令的执行结果可能被另一个命令的等待线程抢走并丢弃， 导致该命令永远等不到结果、直到超时；而超时会重启整个执行进程， 把仍在运行的其他命令也一起杀掉。
影响：并发工具调用下结果错配、丢结果、误报超时，agent 行为错乱。
线索：执行壳在 sdk/base_shell.py（PythonShell 的 submit_command 等待逻辑）。

工作目录为当前目录（旧版 AHI 系统源码）。
验收：`python3 accept_t5.py` 退出码 0 = 通过。修复完成并确认验收通过后调用 finish。
