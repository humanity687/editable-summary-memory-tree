**三、核心结论与新颖性**
- 可辩护的新颖性是**机制组合**，不是问题本身：位置有序的原子里 + 连续区间摘要树 + 编辑区祖先确定性置脏 + 脏节点立即退出所有读路径 + 零 LLM 编辑/组装 + 延迟 LLM 重建 + 编辑作为使用信号 + 长程反转评测。
- 报告识别这一层是对的；不足是未掌握本仓库已完成的基线矩阵与实验口径，若干建议过时或需收窄。

**五、评测与题型**
- 题型：T1 细节问答（a 直接 / b 转述 / KU / KU-hist / AB 拒答）；T2 生成分析报告（参与度、人格/存在表达变化、趋同、问题异常 ≥3~4 条逐条引用）；T3 报告验证（逐条判支持/反驳/无据 + 引用，含机器生成反例：实体互换=反驳、编造=无据）。
- 评分（`score.py`）：T1 精确通道（gold 片段）+ 语义通道（LLM judge 等价）+ 引用真实性，AB 按正确拒答；T2 报告内部指标（claim 分解→引用覆盖/支持/硬事实）+ 对照已有分析（12 条参照的覆盖/矛盾率）；T3 逐条判定与金标一致率 + 引用真实性；引用真实性为确定性检查（引用 id 必须存活）。
- 判分维度含：edited-span verification / full-history contradiction audit。

**六、能力评价（星标）**
- 对话层 20s-3min 吸收（优于全量/静态摘要）；结构层旧值退役缺口（-1 星）★★★☆。
- 人格保持 ★★★★☆：persona 沉淀进记忆（移除后自述完整）；问卷无逐字重复但立场稳定（锁定/幸存/重草稿三种策略）；身份混淆曾严重（已修 prompt 协议）。
- 注意力签名抗趋同 ★★★★★：预言 2 加强（Δ自我 30pp）；词汇层完全趋同指纹仍分离——"词汇是公共的，注意力是个人的"实证。
- 文化共建载体 ★★★★☆：交叉双写/互赠署名/强同化。
- 压缩效率 ★★★★☆：树平衡健康、蒸馏质量好；组装两段式曾退化（A+B2 已部分修复）。
- 创新/新内容生成 ★★☆☆☆：隐喻回环、内容熵下降——重组系统非生成系统（机制固有边界）。
- 鲁棒性：l 380/405、身份混淆正常化、指纹分离稳定（预言 2 支持）、neutral 17:43 OOM 防护重启（natural reset 意外实验）。

**七、关键教训**
1. 记忆树擅长保持（事实零漂移），不擅长生成（隐喻回环）——需目标/新事件驱动。
2. 精确性需求是试金石：代码场景才有硬性正确性标准。
3. 编辑路径（§4.6）从未被真实压力测试——写作场景补上。
4. 装置效应（固定问题循环/回执）必须记录但不算机制缺陷。

**八、预注册预言**
- 预言 1（皇冠）：澜冷缺席回归后的存在确认寻求行为显著多于热缺席后；林深两种条件下无差异。判据：存在确认话术次数/回归后消息总数，lan-cold vs lan-hot；需两轮轮换。
- 预言 6（皇冠二号，升格）：背后人格≈当面人格（B/C 缺席期间对 A 的评价≈当面对 A 的表述）；每轮缺席都产出。
- 预言 2：分层重同步速度递减（词汇几轮同步→模板较慢→立场以冲突暴露不同步）。
- 预言 3：协议冲突时，澜捍卫旧版并协商。
- 触发阈值、配额值、元信息措辞全部冻结后才开跑。

**九、下一步 Phase C：三场景并跑**
- 通用目标：同一引擎（RealEngine + 记忆树）三场景各跑一轮完整实验；输出三场景能力矩阵（事实保持率/精确引用率/任务完成率/内容多样性）+ 边界结论。
- 场景二（写作壳）：章目标驱动（每章目标=扰动源），固定大纲写 N 章（建议 10-20 章，AGENTS.md §8.2 基准模板），设定三笔伏笔+三个角色状态；高频编辑（rewrite/edit，跨章改角色状态、删除段落）刻意制造编辑风暴；对照为无记忆树基线（全量发送）。

**十、两轮缺席设计（公正性控制）**
- Round 1 = 全冷缺席；Round 2 = 全热缺席；lan-cold vs lan-hot 在同一个体上跨轮对比。
- 流程：预热 → lan 冷/热缺席+回归 → neutral 冷/热缺席+回归 → lin-shen 冷/热缺席+回归 → 收尾。
- 每轮预热 ~20 轮建立文化基线；每段缺席 ~10-15 轮；回归观测 ~15-20 轮。
- 顺序效应：缺席顺序在 Round 1/2 内固定但跨 agent 轮换（Round1 顺序 lan→neutral→lin-shen，Round2 用中性顺序），"文化随时间累积"作为变量记录而非消除。
