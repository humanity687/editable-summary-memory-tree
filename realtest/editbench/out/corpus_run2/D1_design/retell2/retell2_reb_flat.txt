这份文档描述的是一套面向长参考资料（如整本书全文）的**分层记忆架构设计**，以小说创作为具体语境书写，核心是让有限上下文窗口能承载超长参考资料。

**定位与问题**：全量发送会爆炸、静态摘要丢细节、关键词检索无状态演化，三法皆失效。

**核心思想四条**：
1. 位置有序的记忆树——参考资料切成原子卡（句），带稳定 ID 与顺序链表；摘要卡按连续区间自底向上合并成树，任何节点=某连续区间的概括。
2. 分辨率随热度变化——近处全分辨率原文，远处降为各级摘要，摘要只保留专有名词、因果链、关键原句；越老越粗但越稳定。
3. 区间失效+懒重建——编辑通过覆盖区间精确失效旧内容，脏卡立即排除出查询，重建推迟到蒸馏时机（零 LLM 的即时编辑路径）。
4. 不可遗忘的事实层——正文流分离的"笔记本"，无衰减、全量存储、按需注入，负责跨区引用（伏笔）与硬约束，不做概率性召回。

**通用化映射**：一句话概述→全局摘要；卷/章→结构单元；beat（叙事节拍）→内容块；伏笔（调度条目）→跨区引用账本；角色状态（状态条目）→事实条目；章节目标（扰动源）→当前任务目标。

**架构**：三轨记忆（当前=进程内+gzip/JSONL 快照，SQLite 为规划目标）——轨道A 小说内容（参考流）：记忆树+原子层+归档（版本谱系）；轨道B 笔记本（事实层）：常驻约束/状态条目/调度条目；轨道C 讨论内容（工作记录）：工具组压缩卡，自然遗忘。

**清单与任务行规则**：必须是事实陈述，清单只列"谁发了什么"（已回复信道剔除），任务行只陈述"本轮有无待回复"；禁止正性行动邀请（实测 41 对重复：29 同轮双发+8 跨轮重发）；未完成事项经检索随扰动源自然浮现；行为约束只写在协议文本。

**self_quota（2026-10-04，默认关的实验操控）**：组装层"自我可见性地板"，保证 `source=="ai"` 原话占组装预算 ≥ `self_quota_ratio`（cap `self_quota_max`）；trim 后补足，位置序注入（kind=`self_quota`，复用 core `_shadow_slot`，渲染成正常自身发言段 `▸〔名字〕`）。

**三份人格（P1/P2/P3）**：P3 名为**澜**，健谈外向、探索欲高、重视记忆（"被记住"是存在感来源），风格轻松直接带活泼幽默，相信时间会证明长期记忆价值。解耦动作写死进 provision：删除墨白原文中"与林深共生/林深是你的同伴"等互指（三份人格必须彼此独立）；删除澜原文中的 tree 工具行（`@recall`/`@note`/`@span`），工具说明统一放 §4 public 提示词；两臂共用同一 3 份 persona_block（人格是控制变量）。

**测试与基准**：§8.1 教训五条——标记完备性、铺陈不变量（无重叠无缝隙按位置序）、编辑边界穷举（书首插入、书尾追加、整块替换、整块删除、跨多节点编辑、区间内含早先中插的编辑、编辑后立即查询）、区间覆盖、回滚对称性。§8.2 基准三组对比（全量发送/摘要拼接/本设计）：长程一致性（延迟回忆，固定大纲写 N 章建议 20→续写第 N+1 章→检测对第 1 章伏笔/角色引用正确率）、状态一致性（注入改名/死亡/改名恢复）、第三项截断。

**设计原则**：简洁（机制少、语义单一、一机制服务多类对象）、涌现（目标特性从机制交互自然出现，写死特判前先问能否由既有机制参数化表达）、判据（硬规则是最后手段）。反面教材（2026-08-29 一天实验）：节点不受注意力保护→统一快衰减→9 轮归零→无限上并→99% 历史压进 1-5 个大节点（组装退化成"两段式"）；教训是对象类别间衰减待遇不对称会杀死层级涌现。经验定律「策展定律」（2026-10-04，M-PR 三次重复）。

**三个粒度描述**：题目；一句话概述→初始根摘要卡（唯一预置摘要，之后根自然演化）；详细参考资料→按句切分为初始原子卡+笔记本条目。

**每章流程**：目标进入（章节目标写入扰动源，含本章出场实体列表→驱动轨道B选取）→预检索（章目标→全树 top-k+逐字通道）→分阶段写作循环（write_stage 段落流粒度写入每句原子卡 / rewrite·edit 走 §4.6 编辑路径 / recall 工具兜底 / ask 用户反馈→protected 卡）→章末（merge pass 蒸馏+脏重建、事实校验对账、版本快照 commit）。

**共现事件表**：A 先验（写入时，语义相似/位置邻近/LLM 判连，可靠性高、信息量低，CAM 领地已裁剪）；B1 组装/注入共现（每次工具调用都发生，可靠性高、信息量中，chatbench direct/hub 已落日志，live 轮注入集未埋点）；B3 引用共现（同一答案引用集内的卡对，可靠性高、信息量高，引用强制作答已有，输出侧未利用）；B5 编辑共现（同一编辑批次，场景依赖、信息量高，cooc γ 已有）；C 元认知（LLM 主动 recall，已证趋零，降级为可选补充）。

**参数取值**：sure_threshold 2.0 / expand_atom_cap 80 / expand_char_cap 3000 / max_hp 150 / merge_pressure_threshold 20 / max_pending_per_loop 3 / force_cooldown_rounds 8 / max_code_per_loop 4 / distill_parallel 4 / snapshot_every_rounds 20。

**评分（score.py，全确定性+单点 LLM judge）**：§5.1 机械 gate 任一失败该 run 作废；G1 隔离无泄漏——检查缺席窗口内留守者收到"你发给 agent:X 未送达"回执数（句首锚定，回执尾部"可用地址"列表含缺席者名不算）。

**实现文件**：`multi/agents/flat-rag/agent.py`（rolling+bge flat RAG，400 字 chunk / top_k=6，每轮 auto-preretrieve，persona 淡出入滚动历史与索引）；`provision.py` instances 模式（architecture: flat_rag、per-agent persona、2 臂×N run×3 agent、独立沙箱根、写 `manifest.json`）；`config/persona_retention.json`（3 persona+分臂工具说明+§6 pinned+judge `pro/thinking`+臂级 `style_alpha/snapshot_every_rounds`）；`pr_score.py`（趋同斜率+judge）。

**风格锚点**：1. 自由文本锚点——agent 用检索到的自身样本每 `snapshot_every_rounds` 轮自生成自然风格自述（旧快照作弱参考、有长度上限、不字段级累积）；2. 内容相关锚点——从自身材料（`source=="ai"` 原话原子+摘要节点整卡含【注】）按与当前待蒸馏内容的语义/词面混合检索挑 top-k（`retrieve_style_samples`；节点命中可选 `expand_self_atoms`），替换了旧的"最近 6 句 recency 池"（recency 池会把当前共享仪式语最先吸进锚点）。prompt 规则 `SUMMARIZE_FACT_STYLED`：允许改措辞/展开顺序/重心，禁止新增或改变事件、数字、专名、归属；`【注】` 独立生成但不渲染。

**persona 约束**：名字占位 {name}，完整文本见 `config/bench_config.example.json` 的 `personas.bench_persona`；禁止在 persona 中写死"我们仨""年轮"等旧实验涌现话术（那是涌现物不是输入）。

**协议参数（冻结）**：wakeup_interval 30s（三 agent）；preheat/absence/observe = 24/12/18 轮（110 轮≈55min/轮）；冷轮缺席顺序 bench-a→bench-b→bench-c（Round1）；热轮缺席顺序反序（c→b→a，Round2，平衡文化累积顺序效应）；seed 42。
