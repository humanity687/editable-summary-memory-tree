这份文档是围绕 **AGENTS.md 分层记忆树 v2 设计规格**（2026-10-04 更新）的多条摘要与原文汇集，主题涵盖分层记忆树机制、注意力窗口与 HP 参数、记忆蒸馏与检索、以及 AHI-Bench 人格保持/趋同实验。以下按主题复述全部关键内容。

**一、分层记忆树总体设计**
- 机制层已实现并多场景实测，涵盖桩、小说写作、聊天智能体、代码智能体、ahi-bench 冷轮、v3 使用信号层、代码审查、M-PR 人格保持实验公平性收口、两臂消息管理对齐，以及 M-PR 首轮对比与消融。
- 长参考资料因超出上下文窗口无法整体处理；全量发送、静态摘要拼接、关键词检索三种现有做法分别存在爆炸、丢细节、无状态演化问题。解决方案为**位置有序记忆树**：将资料切为带稳定 ID 和顺序链表的原子卡（句），摘要卡按连续区间自底向上合并成树，任一节点即某连续区间的概括。
- 记忆系统采用三机制：分辨率随热度变化、区间失效加懒重建、不可遗忘事实层。含三条轨道：轨道 A 小说内容（记忆树+原子层+归档版本谱系）、轨道 B 笔记本（常驻约束/状态条目/调度条目）、轨道 C 讨论内容（工具组压缩卡，自然遗忘）。当前为进程内+gzip/JSONL 快照，SQLite 为规划目标。组装每工具调用一次纯计算；蒸馏仅在章边界或预算超标触发，且 LLM 密集可后台异步（单任务锁）。

**二、HP 与注意力窗口参数**
- hp_merge_threshold 驱动低 HP 判定；父卡创建 HP 为 parent_init_hp 且须大于合并阈值；召回命中项 HP 提升 recall_boost。HP 仅驱动合并优先级压缩，不参与事实层，轨道 B 无 HP。
- 2026-08-12 实现注意力窗口，2026-08-29 节点入窗拍定；动机为编辑风暴中原子卡占满字符预算。注意力窗口为卡数量预算，编辑风暴复述崩溃率 1.5%，冷却窗口缓解症状。
- 2026-08-29 拍定：原子出窗快衰减乘 attention_out_decay，节点出窗衰减仅用 decay；recall_boost 对称生效，HP≥attention_out 自动回窗；merge 需位置连续、成员≥2、低 HP；衰减必至加合并不可逆导致树单调压平为数学必然，唯一稳态通道为 recall_boost 注入平衡，中间层节点数需稳定非零且寿命呈梯度。三层结构为热区裸原子对应工作记忆、记忆树对应……（截断）。
- 聊天适配中原子段名额（used += weight）与衰减倍率（rate *= weight）同时计入，节点 weight 恒为 1；排序键按 HP 降序，无时间序 tie-break；注意力为上游数量约束，assembly_budget 字符为下游硬约束，超预算时新原子保护一轮、旧原子低 HP 优先裁、仍超则硬截断记日志。
- 2026-08-29 至 2026-10-03 期间拍定 attention_atom_cap=40、attention_node_cap=20 等未校准参数及 merge_signal() 单一入口；更新记忆蒸馏机制（退役成员留树内作子节点、force_out 阈值改 attention_out、蒸馏源改干净渲染），realengine._summarize 经 style_provider 与 lan/neutral。
- 注意力窗口参数：attention_atom_cap=40（原子段名额，weight 计）、attention_node_cap=20（节点段名额，全部存活节点平等参与）、attention_out=45.0（HP 低于此值出窗，原子加速衰减）、attention_in_decay=0.5（窗口内衰减倍率，原子与节点同），均未校准（已实现，§4.3b）。
- 中性摘要卡参数：attention_out_decay=3.0、merge_pressure_threshold=20、pressure_threshold=2.0、force_cooldown_rounds=8、hp_merge_threshold=30.0、early_match_threshold=0.5、parent_init_hp=70.0、parent_hp_group_factor=1。

**三、检索与融合**
- 摘要·向量：本地 embedding（如 bge-small-zh）编码摘要卡（创建/重建时按 version 缓存），解决"语义近邻但无词面重叠"。
- 摘要·关键词：bigram 重叠率，解决"摘要恰好含查询字面词"（专名/数字）。
- 原子·关键词粗筛+向量精排：原子双字窗口粗筛（交集≥1）→对粗筛候选（上限 atom_rerank_cap）编码向量精排，解决"细节只存在于原子层"（缺陷 B）；原子文本不可变→原子向量缓存永久有效，无需失效。
- 融合=加权和（w_vec_node/w_bm_node/w_bm_atom，先拍后调）。向量模型缺失时自动退化为关键词单通道（诚实降级）。
- 批量编码（2026-10-03 内存修复）：候选原子/节点向量在一次 enc.encode(list) 内批量编码（EMBED_BATCH=64），禁止逐条 enc.encode——逐条在 MPS 上堆积幽灵内存（实测同批 316 条：逐条 +460MB vs 批量 +69MB），是 pr3 agent 触及 2GB 看门狗重启的根因。并在每次批量编码后调 _empty_mps_cache()（torch.mps.empty_cache()；CPU/无 torch no-op）释放分配器缓存的空闲块（唯一泄漏源；tree ~75MB/min 单调上涨）——清缓存后单 agent 峰值约减半（40 轮 ~1GB），但未根治（仍缓涨；realengine + flat 批量编码两处对称）。
- 贪心选择+路径去重：按分数取最高节点→其到根的整条路径加入结果并从候选池移除→重复直到预算（retrieval_budget）用尽。路径遇脏即停；原子命中不走路径，只注入原子本身。
- 路径上所有节点按位置序注入组装流（小说连贯性优先于相关性；实现=§4.5 影子卡机制，无需全局位置图）。
- 金句/精确引用=逐字通道：原子层字符级匹配（复用双字窗口经验），命中后逐字校验（防 LLM 幻觉改写），与语义检索完全分离。
- 命中项 HP += recall_boost；命中子卡的父卡保留（共存=渐进披露）。
- 激活计数与提升（降雨持久化）：被贪心选中的节点 activation_count += 1；达到 promote_threshold（默认 3）→路径分裂提升：该节点沿祖先路径逐层上提，每层祖先围绕它分裂为左右两个碎片（碎片仅当≥2 个存活子卡才创建，单卡直接上提，碎片置脏→摘要懒重建，LLM 摊入下个 pass），最终节点成为独立顶层树。提升=纯结构操作+置脏，零 LLM 即时路径；提升后的节点带独立 HP，衰减后可再与邻卡合并。
- heat burst 自动下钻披露（2026-09-27 重设计；默认关，接口 auto_expand）：近似 promote 的"上下文内下钻"，只动视野、不动树/账本。信号=回血封顶溢出量（min(hp+recall_boost, max_hp) 被截断部分）：节点热量≥expand_heat_threshold(60) 且预算富余（使用率<expand_ratio=0.85）时，把其直接子卡炸开——全部子卡装得下→替换节点项；否则保留节点+追加装得下的子卡。热量：节点自身命中溢出全额+直接父半权；tick 衰减、不随爆炸消耗。脏/墓碑子卡不入。零 LLM、纯计算。默认关——论文实验分层树臂冻结、全臂 off；首秀=ahi-bench ablation 臂。
- 活性状态（§9.11）：已实现+12 项单测；但在已有冷轮/smoke 实跑中 heat_burst 事件 0 次（短轮命中未到封顶，属预期）。
- 原子通道参数：min_atom_chars / atom_rerank_cap / atom_vec_min = 8 / 60 / 0.2，均未校准。

**四、记忆蒸馏与编辑**
- 记忆蒸馏卡：2026-09-25 校准的 find_similar 逐字重复检测器阈值 0.8（409 句故事×50 facts 实测：原文回原文 max_j≈0.895 命中，转述改写 max_j≤0.29 打不到，0.4 起无关句误命中），语义近邻走混合检索向量通道；预检索在章/段开始时执行、写作中 recall 工具兜底；每次编辑增量入 ledger、章末快照为账本指针、回滚为逆向应用增量后走§4.6 编辑路径。
- 记忆蒸馏摘要卡：EMBED_BATCH=64（2026-10-03 定）；ATOM_CHAR_CAP/ATOM_WEIGHT_CHAR=2000/1000 未校准；find_similar_threshold=0.8 已校准（2026-09-25，§4.7）。

**五、中性摘要卡与边信号**
- 中性摘要卡：边定义为共现信息减相似度先验，信号分 T1 引用句（显式依据#N6039）、T2 未注入命中（cover_span>60 或无覆盖）、T3 改写命中（覆盖跨度≤阈值），复读（bigram Jaccard≥0.8）不记；存储于 sidecar 影子模式，S 为输出句侧车记录，S→A 使用边必记，派生 A↔B 边仅记非冗余对（树亲缘外且端点相似度<θ），只记边不进读路径。
- chatbench demo 中信号源层 β 边唯一来源为显式 recall（C 类元认知），部署中趋零，靠 harness 注入凑出 112 次检索；转化层 conn_weight 带动与 query 错配，u 轮 2082 边、5 簇主题全对，T3 六题引用∩hub 全 0；换信号源只修第一层，带动选择须同时改（交集策略，Phase C）；输出是唯一同时记录供给和选择的信号源。
- 覆盖感知（锚子树含端点，18/207 与更高）提高候选率但可达性上界仍低（5.6–10.8%），冗余边带动约相似度延伸（均 3 个新增），实证冗余边不携带相似度之外信息（§1.3 判据），qa 单题 5 命中经查为 bench-a 工具原子重复 5 次的伪影，结论为约束在边覆盖/可达性，两个语料均为单域短输出史（10/51 答案、单一故事），非冗余跨域连接天然稀疏，符合适用域边界声明（§8/§10），读路径保持关闭。
- 记忆读取侧采用零 LLM 零写树机制，self 配额内二分，锚定切片为 created_round 小于 onset_agent 的 alive 自产原话（source=ai），固定选择加体积上限，红利为渲染确定性使前缀缓存命中；近期切片按剩余配额 recency-first 保留适应性；参数 sq_ratio 为 0.35–0.40，anchor_share 约 0.4 入台账未校准。
