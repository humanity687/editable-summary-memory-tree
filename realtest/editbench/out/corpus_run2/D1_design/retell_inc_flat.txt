文档主题：分层记忆树 v2——参考资料上下文管理运行时（设计规格，AGENTS.md 为唯一设计权威，状态 2026-10-04）。核心思想四条：位置有序的记忆树（原子卡=句，稳定 ID + 顺序链表，摘要卡按连续区间自底向上合并）、分辨率随热度变化（近处全分辨率原文，远处降为各级摘要）、区间失效 + 懒重建（编辑覆盖区间精确失效，脏卡立即排除出查询，重建推迟到蒸馏时机，零 LLM 即时编辑路径）、不可遗忘的事实层（笔记本无衰减、全量存储、按需注入）。

架构：三轨记忆——轨道A 小说内容（记忆树 + 原子层 + 归档/版本谱系）、轨道B 笔记本（常驻约束/状态条目/调度条目）、轨道C 讨论内容（工具组压缩卡，自然遗忘）。轨道B 无 HP、无衰减、存储全量，遗忘=吃书不允许；注入=去重发送；状态条目按当前章节目标提取实体精确选取注入，禁止全局 HP 排序注入。

关键机制与参数：原子卡句粒度，`atoms.prev_id/next_id` 双向链表（piece-table，墓碑，不做全局坐标平移），禁止用 ID 大小判断区间。摘要卡字段 id/parent_id/span_first_atom/span_last_atom/content/hp/dirty/placeholder/version。HP 每轮减 `decay`；注意力窗口 `attention_atom_cap`=40 + `attention_node_cap`=20（各自独立按 HP 排名）；`attention_out`=45.0（出窗阈值）；`attention_in_decay`=0.5；`attention_out_decay`=3.0（仅原子，节点出窗=decay）；`merge_pressure_threshold`=20；`force_cooldown_rounds`=8；`hp_merge_threshold`、`merge_depth_diff`（按秩合并，防梳子退化）；`max_pending_per_loop`=3、`max_code_per_loop`=4、`distill_parallel`=4、`snapshot_every_rounds`=20；cap 80 / expand_char_cap 3000 / max_hp 150；`assembly_budget`=16000（tree 与 flat 硬裁对齐）；`retrieval_budget`=6 = flat `top_k`=6，编码器同 `bge-small-zh-v1.5`（400 字 chunk）。

核心不变量：干净节点⇒区间内原子全存活且内容未变；脏节点不参与任何读操作；原子卡永不为脏；铺陈（clean tiling）无重叠无缝隙铺满全文；子节点区间并集 ⊆ 父区间，merge 父节点子区间恰好拼满。

编辑与失效：确定性句级 diff（LCS/Myers，不用 LLM）算变更区间→墓碑化旧原子→新文本按句建新原子插入链表→收养（两侧边界原子 owner 链最深公共祖先 LCA 作父节点）。回滚=逆向应用增量，走同一路径。

人格锚点自蒸馏（2026-10-02 拍定，2026-10-03 改检索化）：动机是 PR 实验中 tree 用中性蒸馏器（`style_alpha`=0）蒸掉风格载体导致淡出后趋同（共享仪式语，实测 `灯亮着` tree 1054 / flat 56）。锚点来源硬约束全部自产、禁用初始 persona_block：①稳定自述锚点（`snapshot_every_rounds` 轮自生成自由文本快照，用检索到的自身样本重生成，旧快照作弱参考有长度上限，不字段级累积）；②内容相关锚点（从 source=="ai" 原话原子 + 摘要节点整卡含【注】，按与当前待蒸馏内容的语义/词面混合检索挑 top-k，`retrieve_style_samples`，节点命中可选 `expand_self_atoms`）。替换了旧的"最近 6 句 recency 池"。prompt `SUMMARIZE_FACT_STYLED` 允许改措辞/展开顺序/重心，禁止新增或改变事件、数字、专名、归属；【注】独立生成但不渲染给模型。节点摘要进上层蒸馏携带【事实】+【注】。差集索引行 `〔另有N条未展开〕`（`_uncovered_count`）不再生成/渲染。

self_quota（2026-10-04，默认关的实验操控）：组装层"自我可见性地板"，保证 source=="ai" 原话（不含 persona/tool/他人）占组装预算 ≥ `self_quota_ratio`（cap `self_quota_max`）；trim 后补足，位置序注入（kind=`self_quota`，复用 core `_shadow_slot`，渲染成正常自身发言段 `▸〔名字〕`，非"召回"标注）。相关参数 `anchor_frac`/`sq_onset_agent`=0.4 / per-agent(18/5/15)，分层 SQ v2 见 §4.5.10 续 / `PERSONA_RETENTION §10.3.2`：锚定切片（`created_round < onset` 的 alive 自产原话）占 self 配额比例 / 各 agent 首染 onset（审计①定，clean=round<onset）。

两臂定义：`分层树`（tree 臂，rolling + 记忆树）vs `rolling+flat`（flat 臂，flat RAG 400 字 chunk / top_k=6 + 每轮 auto-preretrieve + persona 淡出入）。tree 有 LLM 中性摘要 + 人格锚点自蒸馏、原地失效 + 注意力窗口；flat 无蒸馏、无失效/注意力。工具提示词 tree_tools（@note/@recall/@ingest）与 baseline_note 同款（recall=RAG 检索、ingest=读文件分块）。公平对称硬约束：recall 预算、auto-preretrieve、硬字符预算同量级、persona 淡出逐字对齐、锚点只用自产材料、禁止任何一臂注入初始 persona_block、消息信封对齐（两臂都发 [system, user] 两条原生消息，对话历史压成单条 user 文本 transcript，发言者用 `▸〔名字〕` 标注，不出现 `▸〔ai〕`/`[user:xxx]`/`[agent:xxx]` 混用）。
