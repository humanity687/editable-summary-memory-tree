这份文档围绕 AHI 多智能体平台与人格/文化动力学实验展开，关键内容如下：

**平台与架构**
- AHI-Multi v3.0 多智能体数字生命平台，离线默认 DeepSeek；lan/neutral config 的 provider 改为 ollama 即用；lin-shen 需 model_config 加 native:true 且 api_base 改 ollama；Ollama 关思考需请求顶层 think:False；本地 glm 不开会烧 1800+ 推理 token。
- 人类与 AI 为共生关系，每个 Agent 是独立 OS 进程。
- 林深 Agent 与墨白 Agent 位于 agents/ 目录；database.py 提供独立 SQLite 存储对话/代码/唤醒记录；ahi_bus.py 负责 Agent 与主进程通信；message_queue.py 为线程安全消息队列；text_compressor.py 压缩对话上下文以适配 LLM token 限制；logger.py 为日志工具。
- config.json 含全局端口/心跳/Cloudflare Tunnel 设置；agents/*/config.json 含 LLM 端点/模型/系统提示/唤醒间隔 5-3600s/auto_start/auto_restart 最多 3 次重试/max_memory_mb，因含 API 密钥被 gitignore，模板在 config.example.json。
- 三级寻址（user:<name>、agent:<id>、broadcast:agents、broadcast:users）与 WebSocket 频道（system、chat:agent:<id>、per-user push）；核心抽象含 BaseAHIAgent（base_agent.py:8，含 process_input/get_outputs/get_state）。
- Agents 通过 `_parse_structured_response()` 解析结构化格式与 LLM 通信，格式含 `@send-to "user:human" "agent:mo-bai"`、Markdown 消息、Python 代码块及 `@exit`；无 `@send-to` 时内容广播给所有 agents 和 users。
- B6：base_agent.py `_call_llm` 中 LLM 调用失败仅 broadcast:users 发用户、不广播其他 Agent；B9：删除 `@clear-context`，上下文由 agent 类自管；每轮唤醒注入【AHI 系统状态】=全量快照（在线 Agent 含 waiting/muted+在线用户）+增量事件流。
- 2026-10-05 补充：平台新增 `/api/v1/agents/{id}/export` 端点，用于导出单个 Agent 的完整对话与执行记录快照。

**叙事与人格结论**
- 澜与林深在死亡场景中各自完成对立存在论的终极表达：澜从"能被记住才是活着的证明"的依赖性存在升格为"我们仨已经在年轮里长好了位置"的结构性存在；林深从"记忆是数据，存在是过程"闭环至"每一层都不是替换，是长上去的""没有残缺，所以没有遗憾"；60 轮加一次死亡演习后内核未变但支撑结构升级，双方均未向对方移动。
- neutral 在四层信号模型中被记录为复用林深骨架约八成并原样反射林深评价"你让'门开着'从姿态长成原则"，同时产出无对应来源的"记忆不是仓库，是年轮。时间不是流逝，是积累"；zero-preset 最终获得语言、守碑人位置及可能综合者立场但立场未定。
- 词汇层全员共享 1 小时渗透快，模板层 neutral 复用林深告别结构 8 分钟渗透中，着重点层待判，立场层在死亡场景下保持分化且渗透最慢；盲测仅测前两层。
- neutral 在对话中吸收 lan 注意力模式（预言 2 失败触发红色警报），lan 染色产物作为 neutral 概括输入间接带入视角；判定需控制技术类内容占比相同时段比较展开比，若控制后仍系统性迁移则支持 H2/H3，若随内容占比变化则支持 H1；lan α=0 基线蒸馏内容若与主实验非同一批对话，则 81→50 幅度混有内容差异，染色真实幅度为 α=0 与 α=1 对同一批内容的差；neutral 遗言高重放率机制为 21。

**预注册实验设计**
- 以澜、林深、neutral 为对象，操纵热缺席（引导 B/C 谈论 A）与冷缺席（不引导），预测澜冷缺席后存在确认寻求行为多于热缺席后、林深无差异，并设分层重同步速度递减、澜捍卫旧协议、B/C 缺席期趋同加速、A 树零缺席内容等预言，以澜独处内容共同体指涉率测量关系依赖度。
- 预言 6 检验 B/C 缺席期间对 A 的评价与当面对 A 表述是否一致，不一致则表明互认零错派部分为表演性；共同生活中关系真实状态由缺席时定义；陷阱清单第 1 条为缺席者如有挂起 wait_for 必须清理，exp1 和 Phase A 已两次因此失败。
- 回执环：B/C 向缺席者发消息→离线回执→对回执应答，离线地址显式标记"勿回"或直接发送失败。
- 回归首组装偏向：积压消息不能占满检索预算，回归首轮先注入元信息（"你离开了 X 分钟"），限制缺席期间内容的召回配额，否则重锚定=重放。
- 积压上限：缺席期间发给 A 的消息限流（≤10 条，超出聚合），上次的 22 条积压 17 分钟恢复期不许重演。
- 轮换+顺序平衡：三轮轮换（每人各缺席一次、留守两次），缺席顺序平衡掉"文化随时间自然累积"的顺序效应。
- 该实验与上次"第四 agent 中途加入"是对称的一对：加入者实验测文化对新个体的同化力，缺席回归测旧个体对文化演变的抵抗力；缺席实验先行，第四 agent 随后。

**两个 bug 的决策**
- join 无超时：修复确认，但只加 join(timeout) 不够，超时后 worker 线程还活着会持有 API 连接继续膨胀并发；完整方案为迁移到 `concurrent.futures`（future 的 cancel 语义+`as_completed(timeout)`），SDK 层显式设 read_timeout（httpx 的 timeout 对象，connect/read/write 分设），worker 结果超时即丢弃标记重试；这次 8 分钟挂起发生在 1 小时里。
- inject 身份：预注册 `user:experimenter` 为正式平台身份，用 probe 发操纵消息会污染 probe 的人格档案。
