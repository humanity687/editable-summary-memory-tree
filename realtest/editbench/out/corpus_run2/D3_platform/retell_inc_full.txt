# 分层记忆树 v2 · 参考资料上下文管理运行时 —— 文档复述

## 一、主题与定位

**核心主题**：把一份长参考资料（一本书全文、大型文档集）变成"位置有序、分辨率可变、可编辑演化"的**记忆树**，让 Agent 在有限上下文窗口里稳定工作于任意规模的参考资料之上。

**一句话定位**：长篇小说写作是第一个应用实例；机制通用（章/beat/伏笔 → 结构单元/内容块/跨区引用）。

**核心矛盾**：参考资料是"长期演化的内容"，而现有方案（全量发送、静态摘要拼接、关键词检索）都在用"无状态的文本生成"去逼近它。

**四条核心思想**：
1. 位置有序的记忆树——参考资料切成原子卡（句粒度），按原文顺序组织；摘要卡按连续区间自底向上合并成树。
2. 分辨率随热度变化——近处全分辨率原文，远处降为各级摘要；越老越粗但越稳定。
3. 编辑即失效，重建即蒸馏——修改精确使受影响区间失效，被改内容立即从所有查询排除；编辑路径零 LLM、零阻塞。
4. 不可遗忘的事实层——"笔记本"：无衰减、全量存储、按需注入。

**架构**：三轨记忆（轨道A 参考资料流 = 记忆树+原子层+历史归档；轨道B 笔记本 = 常驻约束/状态条目/调度条目；轨道C 工作记录 = 工具组压缩卡）。

**关键机制**：近热远粗的上下文、区间失效、检索不挑深度、事实不遗忘。

## 五、核心设计决策（为什么是现在这样）

1. **稳定 ID + 顺序链表**（piece-table 式）：编辑不做全局坐标平移；禁 ID 大小比较。
2. **区间覆盖树**，并查集式自底向上合并；无预设根；深度 = 合并历史。
3. **按秩合并**（`merge_depth_diff=1`）：实测 64 批 → 高 9。
4. **禁止单成员块**：父节点创建时子数 ≥2。
5. **收养机制**：缝隙在边界/首尾 → 不收养。
6. **标记置脏**（唯一算法）。
7. **占位解除 = 冷却重建**：全部存活子卡 HP < hot_threshold 时重建。
8. **重建级联**。
9. **影子注入**：位置槽 = 覆盖它的发射项之后，沿 owner 链下钻 O(深度)。
10. **从属标注**（硬要求）：深度缩进 + ⊂父卡 + "召回影子/召回原文"标注。
11. **提升（路径分裂）**：激活计数达阈值 → 沿祖先逐层上提，每层祖先分裂左右碎片。
12. **混合检索三通道**：摘要·向量（bge-small-zh）+ 摘要·关键词（bigram）+ 原子·粗筛+向量精排。
13. **回滚**：undo 逆向走编辑路径；多原子块恢复用末原子锚点。
14. **注意力窗口**（§4.3b，2026-08-12）：窗口内 = 存活原子按 HP 降序排名 ≤ attention_cap 且 HP ≥ attention_out；不对称衰减（窗内 ×in_decay 慢 / 窗外 ×out_decay 快）。
15. **force 合并**（窗外压力）：只合并纯原子段；节点走常规低 HP 合并。
16. **叶子展开（C 机制）**：检索命中节点 → 展开全部后代存活原子为影子。
17. **run2 协议**：`[plan]` 写前预想 → `[recall]`/`[span]` 回想 → 正文 → `[note state]` 状态入笔记本。
18. **冷却窗口**：风暴后 tick(45)→merge→tick(30)→merge；修复复述崩溃（1.5%→30.8%）。
19. **merge 条件式触发**（2026-08-30）：每轮查 `merge_pressure()`；模拟 tiling 峰值 215→143、谷底 127→25。
20. **节点窗口扩展**（2026-08-30）：节点段成员 = 全部存活节点（20 名额）。

## 七、人格保持实验（M-PR / PERSONA_RETENTION）

### 7.1 设计（2026-10-02 定稿）
- 目标：固定模型/协议/人格集，只变记忆架构（分层树 vs rolling+flat RAG），测人格淡出后的保持/趋同。
- 编排 2×3×3：每次 2 实例 × 3 agent（3 份人格）；3 run（seed 42/43/44）= 18 agent-life。
- 人格：林深（理性）/ 墨白（诗意）/ 澜（健谈）。
- 淡出：round 40 全员淡出。
- 模型：被测 glm-4.7-flash 关思考、temp 0.7；judge glm-4.7-flash 开思考、temp 0。
- 主判据：趋同斜率 `tree < baseline`；judge 遵从率 `tree > baseline`。

### 7.2 首轮结果（pr5，2026-10-04）
- **flat 两主指标胜（反向）**：趋同斜率 tree **+0.031** vs flat **−0.003**；judge 遵从率 tree **0.894** vs flat **0.940**（strict other→drift：0.825 vs 0.917）。
- pr5_neutral（tree α=0）：趋同反而更狠（+0.043）；遵从率更低（均值 0.660 vs 0.894；墨白 1.0→0.472）。
- **结论**：① 趋同根因 = 树记忆管线 + 跨 agent 耦合，不是 `style_alpha`；② `style_alpha=1.0` 有效保人格（遵从 +0.23），代价 = 内存 +55%（3.6→1.6GB）。
