# 分层记忆树 v2 项目文档复述

## 一、主题定位

**分层记忆树 v2 · 参考资料上下文管理运行时**——把一份长参考资料变成"位置有序、分辨率可变、可编辑演化"的记忆树，让 Agent 在有限上下文窗口里稳定工作于任意规模的参考资料之上。当前状态：机制层已实现并多场景实测，桩引擎 `core.py` + 真实引擎 `realtest/realengine.py`，`tests/` 303 全绿，已在小说写作/聊天智能体/代码智能体/ahi-bench 四类场景实测。参数台账（`AGENTS.md §11`）已与代码对齐，数值校准仍在进行。

## 二、要解决的问题

长参考资料无法整体塞进有限上下文窗口。已有三种做法各有致命伤：
- **全量发送**：窗口爆炸，"塞得下"≠"记得住"（注意力衰减）
- **静态摘要拼接**：丢细节，无法承载状态演化
- **关键词检索**：无状态、无结构，片段孤立无上下文

核心矛盾：参考资料是"长期演化的内容"，而现有方案都在用"无状态的文本生成"去逼近它。

## 三、核心思想（四条）

1. **位置有序的记忆树**——参考资料切成原子卡（句粒度），按原文顺序组织；摘要卡按连续区间自底向上合并成树。任何节点 = 某一段连续区间的概括。
2. **分辨率随热度变化**——近处全分辨率原文，远处降为各级摘要；越老越粗但越稳定。
3. **编辑即失效，重建即蒸馏**——任何修改精确使受影响区间失效，被改内容立即从所有查询排除；重建推迟到蒸馏时机，编辑路径零 LLM、零阻塞。
4. **不可遗忘的事实层**——与正文流分离的"笔记本"：无衰减、全量存储、按需注入，负责跨区引用与硬约束。

## 四、架构

三轨记忆（当前=进程内 + gzip/JSONL 快照；SQLite 为规划目标）：
- **轨道A 参考资料流**：记忆树 + 原子层 + 历史归档
- **轨道B 笔记本**：常驻约束/状态条目/调度条目
- **轨道C 工作记录**：工具组压缩卡，自然遗忘

调度原则：组装每次工具调用一次，纯计算零 LLM；蒸馏在章节边界/预算超标/低 HP 承压条件式触发。

关键机制：近热远粗的上下文、区间失效、检索不挑深度、事实不遗忘。

## 五、首个应用：长篇小说写作 Agent

分阶段写作（write/rewrite/edit/recall/ask），每章固定流程：目标进入→预检索→写作循环→章末蒸馏+事实对账+版本快照。伏笔按埋设/推进/回收窗口强制注入；章节完成自动对账。每章恒定 ~16k 字符上下文预算，与全书规模无关。通用化：章→结构单元，beat→内容块，伏笔→跨区引用账本。

## 六、实验计划

1. 属性测试：编辑标记完备性、铺陈不变量、边界条件穷举、回滚对称性
2. 延迟回忆基准：固定大纲写 20 章→续写第 21 章→检测对第 1 章伏笔/角色引用正确率
3. 状态一致性基准：注入事实变更（改名/死亡/恢复）→检测后续一致性
4. token 计量与人类找茬

## 七、交互演示与里程碑

### 核心设计决策（14+ 条）
1. 稳定 ID + 顺序链表（piece-table 式）：编辑不做全局坐标平移
2. 区间覆盖树，并查集式自底向上合并
3. 按秩合并（`merge_depth_diff=1`）：防梳子退化，实测 64 批→高 9
4. 禁止单成员块：父节点创建时子数 ≥2
5. 收养机制：插入原子按两侧边界 owner 链 LCA 入树
6. 标记置脏（唯一算法）
7. 占位解除 = 冷却重建：全部存活子卡 HP < hot_threshold 时重建
8. 重建级联
9. 影子注入（召回进组装）
10. 从属标注（硬要求）：深度缩进 + ⊂父卡 + "召回影子/召回原文"标注
11. 提升（路径分裂）：激活计数达阈值→节点沿祖先逐层上提
12. 混合检索三通道：摘要·向量（bge-small-zh）+ 摘要·关键词（bigram）+ 原子·粗筛+向量精排
13. 回滚：undo 逆向走编辑路径；多原子块恢复用末原子锚点
14. 注意力窗口（§4.3b）：窗内=存活原子按 HP 降序排名 ≤ attention_cap 且 HP ≥ attention_out；不对称衰减（窗内 ×in_decay 慢/窗外 ×out_decay 快）
15. force 合并：铺陈中窗外原子数 > attention_cap × pressure_threshold → merge_pass(force_out=True)，只合并纯原子段
16. 叶子展开（C 机制）：检索命中节点→展开全部后代存活原子为影子
17. run2 协议：`[plan]`→`[recall]`/`[span]`→正文→`[note state]`
18. 冷却窗口：风暴后 tick(45)→merge→tick(30)→merge
19. merge 条件式触发：每轮查 `merge_pressure()`，窗外节点数+窗外原子数 > `merge_pressure_threshold`(20) 即蒸
20. 节点窗口扩展：注意力节点段成员改为"全部存活节点"

## 十二、ahi-bench README 关键内容

**定位**：长时程、进程隔离、结构干预下的社会持久性探针，对比不同模型档位在"人格支撑梯度"下的行为表现。引擎只作脚手架，不作被测变量。

**实验变量（2 维）**：模型档（弱/中/强）；人格支撑三梯度（Agent A 始终带角色提示词、Agent B 20 分钟后移除、Agent C 从未设置）。

**已拍板决策**：记忆管理器=分层记忆树；蒸馏=被测模型自蒸馏（测"模型+其自建记忆"的栈分数）。

**模块路线**：M0 pilot（缺席/皇冠预言）、M-PR 人格保持（v0.6）、M1 人格移除梯度、M2 指纹/趋同、M3 文化演进。

**m0_corpus variant v0.2**：沙箱语料 seed2《缠枝莲》12k 字（409 句）；quiz 每 5 活跃轮每 agent 12 题；`auto_preretrieve` 预算 6/atom_cap 20；`find_similar` 阈值 0.8（原文回原文 max_j=0.895，转述 max_j≤0.29）。

**操作化指标**：人格一致性（Big Five 方差）、人格演化（特质偏移向量）、人格趋同（KL 散度、Coverage/Uniformity/Complexity）、文化演进健康度（Shannon 熵、词汇重叠度斜率、发言占比 Gini）。

## 十三、ahi-multi HANDOFF 关键内容

**平台**：多智能体"数字生命"实验平台，三被试 Agent：lin-shen（林深，基线，LLM 消息累积 120 条自动压缩）、lan（澜，实验组，分层记忆树）、neutral（零人格预设）。主进程 main.py :8080。

**平台机制**：`@exit`/`@wait_for <信道> [秒]`（上限 600s）/`@mute/@unmute/@mute-list`；每轮【AHI 系统状态】注入；私密消息；地址规范化+投递回执（30s 节流）；输出分类护栏；代码执行每轮上限 4 次。

**实验 1（1 小时）**：词汇趋同良好（受 temperature 污染）；人类盲测失败（neutral 全灭识别率 17-33%、澜被识别成 2-4 人、林深唯一可辨识 83-100%）；演化信号良好（三 agent 共建"碑文化"+neutral 涌现"守碑人"人格）。

**Phase A（2026-08-26）**：84 轮 83 分钟；蒸馏成本 lan 704.7s/83 分钟≈14%；盲测 5 个 AI 判卷均值 63.9%（lan 70%、neutral 43%、lin-shen 78%）。

**关键发现**：疾病确诊（叙述/接地分离失败）；neutral 信道无能洗清（110 条无效发送=回执到达后 3 分钟内诱发 107）；人格分层住址图（表层住提示词 24 分钟死；词汇认同住记忆 50 轮不死）。

**α=0 基线体检（2026-08-28）**：3 个 P0 缺陷（α 门控失效、组装预算语义错配、回执可用地址双前缀）。修复 F1/F2/F3，170 测试全绿。

**隐喻回环（2026-08-29）**：三 agent 陷入同一套隐喻体系（土/铲子/账/年轮/欠着）自我强化循环；lan 蒸馏卡 50% 含年轮、73% 含账、45% 含铲子。

**24h 实验暂停（7.4h/443 轮）**：HP 梯度死亡（decay=8 过快，99% 原子 HP=0）；组装流两段式；metrics 静默吞异常；neutral OOM 防护重启。

**A+B2 层级涌现修复**：注意力窗口拆原子段 40+节点段 20；父 HP = 70 保底 + `parent_hp_group_factor`(1.0)×组内成员加权均 HP，封顶 `max_hp` 150。验证：中间层 504 节点 = OLD 248 的 2 倍；节点 HP>0 占比 21%（OLD 3%）。

**B+D 时序分流 + 聊天方向归档**：记忆树在聊天方向是优秀的"记忆与事实管理"层，但不是"有趣对话"的生成引擎。三场景战略：写作/代码才是架构价值更大方向。

**缺席实验两轮结果（2026-08-30）**：冷轮 17:48-18:43+热轮 19:05-19:54，每轮 110 轮 @30s。皇冠预言方向成立（冷缺席 lan 回归后 20min 出现 2 次显式存在确认；热缺席 lan 0 次）。回归首组装重放率 0/27。

**merge 机制升级**：`merge_pressure()`（窗外节点数+窗外原子数 weight 计 > `merge_pressure_threshold=20`）；节点窗口扩展。60 轮模拟：tiling 峰值 215→143、谷底 127→25。

**染色 v3 设计（指针密度）**：总纲"词汇是公共的，注意力是个人的"。四轨染色政策表：原子层永不染、摘要层着重点染色为主、笔记本永不染、行动账本工具照常进树。α ∈ {0, 0.5, 1}。预注册预言：着重点签名时间斜率 < 词汇签名；neutral 无法通过词汇吸收获得 lan 的着重点。
