# 复述：分层记忆树 v2 项目全部关键内容

## 一、主题与定位

这是一套**分层记忆树 v2 · 参考资料上下文管理运行时**。核心目标：把一份长参考资料变成"位置有序、分辨率可变、可编辑演化"的记忆树，让 Agent 在有限上下文窗口里稳定工作于任意规模的参考资料之上。状态：机制层已实现并多场景实测，桩引擎 `core.py` + 真实引擎 `realtest/realengine.py`，`tests/` 303 全绿，已在小说写作/聊天智能体/代码智能体/ahi-bench 四类场景实测。参数台账（`AGENTS.md §11`）已与代码逐项对齐，数值校准仍在进行。

近期（2026-10）：人格保持实验完成 tree/flat 首轮对比 + `style_alpha` 消融 + `self_quota` 操控（120 轮）；结论：趋同根因 = 树管线/跨 agent 耦合；`self_quota` 抬自我可见性有效（词面趋同归零）但**未止住人格漂移**（p1 锚到"污染态自我"）。

## 二、要解决的问题与核心思想

三种既有做法各有致命伤：全量发送（窗口爆炸+注意力衰减）、静态摘要拼接（丢细节）、关键词检索（无状态无结构）。核心矛盾：参考资料是长期演化的内容，现有方案却用无状态文本生成去逼近它。

**核心思想四条**：① 位置有序的记忆树（原子卡=句粒度，摘要卡按连续区间自底向上合并）；② 分辨率随热度变化（近处全分辨率原文，远处降为各级摘要）；③ 编辑即失效、重建即蒸馏（修改精确使区间失效，编辑路径零 LLM、零阻塞）；④ 不可遗忘的事实层（笔记本：无衰减、全量存储、按需注入）。

## 三、架构

三轨记忆：轨道A 参考资料流（记忆树+原子层+历史归档）、轨道B 笔记本（常驻约束/状态条目/调度条目）、轨道C 工作记录（工具组压缩卡，自然遗忘）。调度原则：组装=每次工具调用一次、纯计算零 LLM；蒸馏=章节边界/预算超标/低 HP 承压条件式触发。当前=进程内 + gzip/JSONL 快照；SQLite 为规划目标。

关键机制：近热远粗的上下文、区间失效、检索不挑深度（对整棵树打分，命中节点连同祖先路径注入）、事实不遗忘。

## 四、首个应用与实验计划

长篇小说写作 Agent：分阶段写作（write/rewrite/edit/recall/ask），每章目标进入→预检索→写作循环→章末蒸馏+事实对账+版本快照；伏笔按埋设/推进/回收窗口强制注入；每章恒定 ~16k 字符上下文预算。通用化：章→结构单元，beat→内容块，伏笔→跨区引用账本。

实验计划：属性测试、延迟回忆基准（20 章→续写第 21 章）、状态一致性基准、token 计量与人类找茬。

交互演示：`visualize.html`（记忆树/原子链/组装输出三视图，18 步演示剧本）。

实施里程碑：Step 1 原子层+顺序链表+确定性 diff+编辑/失效路径；Step 2-3 铺陈组装+HP/蒸馏；Step 4-5 检索+笔记本/工作记录；Step 6-7 写作工作流+基准实验与参数校准。

## 五、核心设计决策（HANDOFF §3）

1. 稳定 ID + 顺序链表（piece-table 式），禁 ID 大小比较；2. 区间覆盖树，并查集式自底向上合并；3. 按秩合并（`merge_depth_diff=1`）；4. 禁止单成员块（父节点子数 ≥2）；5. 收养机制（插入按两侧边界 owner 链 LCA 入树）；6. 标记置脏（删除爬墓碑卡链、插入爬收养链）；7. 占位解除=冷却重建；8. 重建级联；9. 影子注入；10. 从属标注（深度缩进 + ⊂父卡 + "召回影子/召回原文"）；11. 提升（路径分裂）；12. 混合检索三通道（摘要·向量 bge-small-zh + 摘要·关键词 bigram + 原子·粗筛+向量精排）；13. 回滚（多原子块恢复用末原子锚点）；14. 注意力窗口（不对称衰减：窗内 ×in_decay 慢/窗外 ×out_decay 快）；15. force 合并（只合并纯原子段）；16. 叶子展开（`EXPAND_ATOM_CAP/CHAR_CAP`）；17. run2 协议（`[plan]`/`[recall]`/`[span]`/`[note state]`）；18. 冷却窗口（风暴后 tick(45)→merge→tick(30)→merge）；19. merge 条件式触发（`merge_pressure_threshold`=20）；20. 节点窗口扩展（全部存活节点平等参与 20 名额）。

## 十、结论

- 编辑一致性靠结构（复述零残留仅 tree，full/flat 20-34% 不可补）；召回/理解靠模型（思考 +6~+19）；强向量 bge-large 无增益
- 趋同根因 = 树管线/跨 agent 耦合，非 `style_alpha`；`style_alpha=1.0` 有效保人格但内存 +55%
- 自我可见性 = 必要不充分（H-SQ1/3/4 达标，H-SQ2 未达标）
- 使用信号层：recall 共现边基本是向量相似度冗余；协同层不接 live
- 论文 Paper 1 已可开写，但缺"3 文档 × 3 seed"硬门槛
- 聊天方向已归档：记忆树是优秀的记忆与事实管理层，但不是有趣对话的生成引擎
