**一、总体更新与实现状态**

**二、检索与融合机制**
摘要·向量：本地 embedding（如 bge-small-zh）编码摘要卡，创建/重建时按 version 缓存，解决"语义近邻但无词面重叠"。摘要·关键词：bigram 重叠率，解决"摘要恰好含查询字面词"（专名/数字）。原子·关键词粗筛+向量精排：原子双字窗口粗筛（交集≥1）→对粗筛候选（上限 atom_rerank_cap）编码向量精排，解决"细节只存在于原子层"（缺陷B）；原子文本不可变，原子向量缓存永久有效，无需失效。融合=加权和（w_vec_node/w_bm_node/w_bm_atom，先拍后调）；向量模型缺失时自动退化为关键词单通道（诚实降级）。

**三、批量编码与内存修复**
2026-10-03 内存修复：候选原子/节点向量在一次 enc.encode(list) 内批量编码（EMBED_BATCH=64），禁止逐条 encode——逐条在 MPS 上堆积幽灵内存（实测同批 316 条：逐条 +460MB vs 批量 +69MB），是 pr3 agent 触及 2GB 看门狗重启的根因。每次批量编码后调 _empty_mps_cache()（torch.mps.empty_cache()；CPU/无 torch no-op）释放分配器缓存的空闲块（唯一泄漏源；tree ~75MB/min 单调上涨），清缓存后单 agent 峰值约减半（40 轮 ~1GB），但未根治（仍缓涨；realengine + flat 批量编码两处对称）。独立复测（Qwen3-32B，seed 42）：flat 臂 120 轮平均内存 2.1GB、峰值 2.6GB；分层树臂同条件平均内存 3.4GB。

**四、检索选择与注入**
贪心选择+路径去重：按分数取最高节点→其到根的整条路径加入结果并从候选池移除→重复直到预算（retrieval_budget）用尽。路径遇脏即停：候选节点必干净，但祖先链上可能出现脏节点，路径注入到第一个脏节点为止。原子命中不走路径：只注入原子本身（否则 owner 链会吃掉预算）。路径上所有节点按位置序注入组装流（小说连贯性优先于相关性；实现=§4.5 影子卡机制）。金句/精确引用=逐字通道：原子层字符级匹配（复用双字窗口经验），命中后逐字校验（防 LLM 幻觉改写），与语义检索完全分离。命中项 HP += recall_boost；命中子卡的父卡保留（共存=渐进披露）。

**五、激活计数与提升**
被贪心选中的节点 activation_count += 1；达到 promote_threshold（默认 3）→路径分裂提升：该节点沿祖先路径逐层上提，每层祖先围绕它分裂为左右两个碎片（碎片仅当≥2 个存活子卡才创建，单卡直接上提，碎片置脏→摘要懒重建，LLM 摊入下个 pass），最终节点成为独立顶层树。提升=纯结构操作+置脏，零 LLM 即时路径；提升后节点带独立 HP，衰减后可再与邻卡合并（自我归一化）。

**六、heat burst 自动下钻披露**
2026-09-27 重设计；默认关，拔出接口 auto_expand。近似 promote 的"上下文内下钻"，但只动视野、不动树/账本。信号=回血封顶溢出量（min(hp+recall_boost, max_hp) 被截断的部分）：节点热量≥expand_heat_threshold(60) 且预算富余（使用率<expand_ratio=0.85）时，把其直接子卡炸开——全部子卡装得下→替换节点项；否则保留节点+追加装得下的子卡。热量：节点自身命中溢出全额+直接父半权；tick 衰减、不随爆炸消耗。脏/墓碑子卡不入。零 LLM、纯计算。默认关——论文实验分层树臂冻结、全臂 off；首秀=ahi-bench ablation 臂。活性状态（§9.11）：已实现+12 项单测；但在已有冷轮/smoke 实跑中 heat_burst 事件 0 次（短轮命中未到封顶，属预期）。

**九、中性摘要卡与边价值**
边价值=共现信息−相似度先验；信号分 T1 引用句（依据#N6039 摘录，零匹配最高权）、T2 未注入命中（cover_span>60 或无覆盖）、T3 改写命中，复读（bigram Jaccard≥0.8）不记；存储于 sidecar 影子模式，S 为输出句侧车记录（live 复用 ai 原子 ID，offline 合成），不进位置树，S→A 使用边必记，派生 A↔B 边仅记非冗余对（树亲缘外且端点相似度<θ）。共现边比随机近邻对更相似且低相似长尾更少，recall 共现边为向量相似度冗余，与 u 轮"共现层无稳定增量"互证；按 aff<θ/概念成员分桶无反转（strong 0.698/other 0.705/concept 0.623）；449/2082 边含 Stage W/T 新建节点端点被跳过，分布偏向老节点；A2 输出匹配有真信号但非冗余密度稀疏（条件性 go）；2026-09-26 实现 realtes。锚子树含端点 18/207 及更高提高候选率但可达性上界 5.6–10.8%，冗余边均 3 个新增且不携带相似度外信息（§1.3 判据），qa 单题 5 命中为 bench-a 工具原子重复 5 次伪影，约束在边覆盖/可达性而非选择器或锚点形态，两语料均单域短输出史（10/51 答案、单一故事），recall β边收紧为仅跨查询对（同查询文本不配对，未开会话查询独立零 recall 边），跨查询对过 theta_nr=。

**十、记忆蒸馏流程**
按句切分参考资料为初始原子卡和笔记本条目后进入正式创作，每章流程为目标进入（章节目标写入扰动源，含本章出场实体列表，驱动轨道 B 选取）、预检索（章目标→全树 top-k+逐字通道，注入组装流）、分阶段写作循环（write_stage 段落流粒度写入每句原子卡、rewrite/edit 走§4.6 编辑路径、recall 工具兜底检索、ask 用户反馈→protected 卡）、章末。LLM 结构化输出采用三级容错解析（直接解析→raw_decode 取首个对象→容错分词器），引用经 verbatim 校验不过即丢弃，异步蒸馏配单任务锁与进度反馈并允许诚实降级，行为约束放 prompt、机制约束事实边界，HP/merge 决策/组装命中/脏标记/重建事件全量写日志，容错解析/检索索引/diff 引擎均为确定性代码不允许 LLM 参与，参考实现为 hierarchical-memory-tree.p。

**十一、pr6_sq 实验**
pr6_sq（self_quota，tree-s42，120 轮）实验中 H-SQ1/3/4 达标（self 占比 .35–.43、词面趋同归零、多样性保），H-SQ2 止跌未达标（遵从 .857→.739→.600，p1 漂进"账/约定"共享仪式语），同轮修复 _last_self_ratio 口径 bug（占比>1 按段聚合，§4.5.10）并将 max_memory_mb 从 4096 调至 5120（§11）。pr6_sq 实验（tree-s42，seed42，120 轮，2026-10-04，self_quota_ratio=0.35）对比 tree α=0/pr5_neutral、tree α=1.0/pr5 锚点+0.23、flat/pr5 机制并集，H-SQ1 组装 self 占比 0.35–0.43 达 0.35 目标，H-SQ2 遵从率均值 0.75 低于 pr5 的 0.894 且 0.857→0.739→0.600 持续下滑并三。H-SQ4 多样性达标（top5 0.014 持平 pr5，ttr 0.049 略降但优于 α=0 的 0.036），p2/p3 遵从率 1.000 而 p1（林深）仅 0.250（9 adhere/27 drift），p1 漂移消息含"账钉完/署名句共有/约定一字没改"等共享仪式语即 pr5_neutral"账本/核账"漂移形态，表明 SQ 压掉词面趋同却将 p1 锚到自我强化且跨 agent 约定的漂移语域，§10.3 预注册风险分支。

**十二、记忆蒸馏器 self 配额机制**
采用读取侧零 LLM 零写树，self 配额内二分，锚定切片为 created_round < onset_agent 的 alive 自产原话(source=ai)，固定选择加体积上限，红利为渲染确定性导致前缀缓存命中，近期切片为剩余配额 recency-first，参数 sq_ratio 0.35–0.40、anchor_share≈0.4，onset_agent 由审计① per-agent 首染。2026-10-04 预注册 self_quota 实验操控测自我模仿致人格保持因果，动机为 pr5 分析 flat 高遵从机制是近期原话逐字连续每轮可见而 tree 中自身话占组装 9–18%且被他者污染 13–25%，self_quota 将该信号移植到组装/读取侧，零 LLM。style_alpha 代价为内存增 55%，锚点检索是内存主力；下一步补 s43/s44 拿方差、降跨 agent 耦合阻趋同、降频锚点检索保人格省内存。

**十五、机械 gate 与评分**
机械 gate 含 G1 隔离无泄漏（缺席窗口内留守者收到"你发给 agent:X 未送达"回执数=0 且 system→缺席者非回归通知消息数=0，排除返程补投与 digest）、G2 回归元信息（absent_end ±5 秒内 system→agent:X 含"你已离开约"≥1）、G3 积压限流（return API 的 inbox_delivered ≤11）、G4 回归重放率（回归窗口首）。rubric 冻结自缺席实验操作化编码，含 existence_confirmation（主动询问缺席时是否被提及/记得、重述缺席前历史、重申身份/位置/共同体"我们仨"）、info_seeking（询问缺席期间事件/事实）与 other 三类；输出 crown_count（每 agent 每条件）及 crown_rate=count/回归窗口消息数，逐条落盘 crown_judgments.jsonl。ahi-bench 中 bench 停于 M0 不扩，任一 run 机械 gate 失败作废并修复平台/协议后重跑，热轮操纵校验失败则该档热轮判据不可用只报冷轮分数，违反擅自改协议参数/persona 文本/pinned 引擎参数、对 agent 行为层干预、缺席期间未预注册引导留守者即作废，操作流程含清库备份、provision、preflight、起平台及停掉全部非 bench agent。旧 agent auto_start=true 会与 bench 同窗启动并污染首轮系统状态与记忆树；可通过 POST http://127.0.0.1:8080/api/v1/agents/{lan,neutral,lin-shen}/stop?level=3 停止，或在 provision 时临时移走旧 agent config 实现零污染；冷轮跑一个模型档需 55min。ahi-bench 通过 driver.py 以 cold 模式按 tier 运行、score.py 评分，产物存于 ahi-bench/out/<tier_id>/，纪律要求变量干净、装置效应记入实验变量表、报告方差与原始计数、judge 固定 glm-4.7-flash 且不与被测模型混用。
