这份文档是《分层记忆树 v2 · 参考资料上下文管理运行时（设计规格）》（AGENTS.md），主题是把长篇参考资料（第一应用实例是长篇小说写作）装进有限上下文窗口的机制设计。核心思想四条：位置有序的记忆树（原子卡=句粒度，稳定 ID + 顺序链表，摘要卡按连续区间自底向上 merge 成树）；分辨率随热度变化（近处全分辨率原文，远处降为各级摘要）；区间失效 + 懒重建（编辑覆盖区间精确失效，脏卡立即排除出一切查询，重建推迟到蒸馏时机，零 LLM 即时编辑路径）；不可遗忘的事实层（笔记本）。设计原则为简洁、涌现、判据（硬规则是最后手段）。反面教材为 2026-08-29 实验：节点不受注意力保护 → 统一快衰减 → 9 轮归零 → 无限上并 → 99% 历史压进 1-5 个大节点，组装退化成"两段式"；教训是对象类别间衰减待遇不对称会杀死层级涌现。经验定律「策展定律」标注 2026-10-04、M-PR 三次重复。

架构为三轨记忆：轨道A 小说内容（记忆树 + 原子层 + 归档/版本谱系）、轨道B 笔记本（事实层：常驻约束/状态条目/调度条目，无 HP、无衰减、存储全量，遗忘=吃书不允许）、轨道C 讨论内容（工具组压缩卡，自然遗忘）。通用化映射：一句话概述=全局摘要，卷/章=结构单元，beat=内容块，伏笔=跨区引用账本，角色状态=事实条目，章节目标=扰动源。

关键参数：decay、hp_merge_threshold、attention_atom_cap=40、attention_node_cap=20、attention_out=45.0（出窗阈值）、attention_in_decay=0.5、attention_out_decay=3.0（仅原子；节点出窗=decay）、merge_pressure_threshold=20、force_cooldown_rounds=8、merge_depth_diff、retrieval_budget=6、assembly_budget=16000、snapshot_every_rounds=20、self_quota_ratio / self_quota_max（2026-10-04 默认关的实验操控，"自我可见性地板"，保证 source=="ai" 原话占组装预算比例，trim 后补足，位置序注入，kind=self_quota，复用 core `_shadow_slot`，渲染成正常自身发言段 `▸〔名字〕`）、anchor_frac=0.4、sq_onset_agent per-agent(18/5/15)、expand_char_cap 3000、max_hp 150、max_pending_per_loop 3、max_code_per_loop 4、distill_parallel 4、被测温度 0.7、judge 温度 0、judge 模型 glm-4.7-flash（thinking 开）、wakeup_interval 30s、总轮数 120–180（fade 40）、preheat/absence/observe = 20/12/18、seed 42、话题池 12 题、B 移除在 agent 内轮 40、缺席模式 alone。

核心不变量：干净节点⇒区间内原子全存活且内容未变；脏节点⇒不参与任何读操作；原子卡永不为脏；铺陈（clean tiling）无重叠无缝隙铺满全文；子节点区间并集 ⊆ 自身区间，merge 父节点子区间恰好拼满父区间。禁止用 ID 大小做区间判断。

编辑路径（§4.6）：确定性句级 diff（LCS/Myers，不用 LLM）→ 墓碑化旧原子 + 新原子插入链表 → 收养（取插入位置两侧边界原子 owner 链的最深公共祖先 LCA 作父节点）→ 爬链置脏 → ledger 账本；回滚=逆向应用增量，走同一条编辑路径。

人格锚点自蒸馏（2026-10-02 拍定，2026-10-03 改检索化）：动机是 PR 人格保持实验中 tree 用中性蒸馏器（style_alpha=0）把人格风格载体蒸掉导致趋同（共享仪式语，实测"灯亮着" tree 1054 / flat 56）。锚点硬约束全部自产、禁用初始 persona_block：① 稳定自述锚点=agent 定期（snapshot_every_rounds）自生成自由文本风格快照（用检索到的自身样本重生成，旧快照弱参考、有长度上限、不字段级累积）；② 内容相关锚点=从自身材料（source=="ai" 原话原子 + 摘要节点整卡含【注】）按与当前待蒸馏内容的语义/词面混合检索挑 top-k（realengine.retrieve_style_samples，节点命中可选 expand_self_atoms）。取代旧的"最近 6 句 + 8 字段快照"（recency 池被共享仪式语污染、快照单调累积而废弃）。prompt 规则 SUMMARIZE_FACT_STYLED：允许改措辞/展开顺序/重心，禁止新增或改变事件、数字、专名、归属；【注】独立生成但不渲染给模型。

实验设计：两臂 = `分层树`（tree 臂，rolling+tree）vs `rolling+flat`（flat 臂，rolling + bge flat RAG，400 字 chunk / top_k=6 + 每轮 auto-preretrieve + persona 淡出入滚动历史与索引）。公平对称硬约束：recall 预算 flat top_k=6 = tree retrieval_budget=6，编码器同 bge-small-zh-v1.5；两臂每轮都 auto-preretrieve；硬字符预算同量级（tree assembly_budget=16000，flat 单条 transcript 同样硬裁、裁最旧历史）；persona 淡出文本/时机/移除方式逐字对齐；锚点只用自产材料，禁止任一臂注入初始 persona_block；消息信封对齐（2026-10-03）两臂都发 [system, user] 两条原生消息，对话历史压成单条 user 文本 transcript，发言者统一用名字标注 `▸〔名字〕`，不出现 `▸〔ai〕`/`[user:xxx]`/`[agent:xxx]`。人格集 3 份冻结（来源=旧 ahi-multi）：P1 林深（理性冷静内省、简洁有力绝不啰嗦）、P2 墨白（诗意灵动敏感温暖）、P3 澜（健谈外向、探索欲高、重视记忆、相信时间证明长期记忆价值）。解耦动作：删除墨白原文中"与林深共生/林深是你的同伴"等互指，删除澜原文中的 tree 工具行，工具说明统一放 §4 public 提示词，两臂共用同一 3 份 persona_block。禁止在 persona 中写死"我们仨""年轮"等旧实验涌现话术。

指标与预注册判据：主指标趋同（臂内 3 人格两两 bigram Jaccard / 词汇分布 KL 的淡出后斜率，10 分钟窗口），预注册 slope_tree < slope_baseline；一致性（主）judge(pro+thinking) 逐消息判是否符合初始人格的淡出后遵从率，adhere_tree > adhere_baseline。机械 gate G1 隔离无泄漏等。基准三组对比（全量发送/摘要拼接/本设计）：长程一致性（固定大纲写 20 章→续写第 N+1 章→检测对第 1 章伏笔/角色引用正确率）、状态一致性（角色改名/死亡/改名恢复）、token 计量、人类找茬（读 10 章找连续性 bug）。属性测试 §8.1：标记完备性、铺陈不变量、编辑边界穷举、区间覆盖、回滚对称性。

M-PR 实验结果：pr6_sq（tree-s42，120 轮，α=1+SQ .35）H-SQ1/3/4 达标、H-SQ2 未达标（回声风险实体化）。四判据裁决：conv slope (all) pr5 tree +0.0313 / pr5_neutral +0.0422 / pr6_sq −0.0011（H-SQ3 ✓）；conv slope (to_user) +0.0215 / +0.0443 / +0.0118；遵从率 early/mid/late pr5 tree .959/.875/.773、pr5_neutral .709/.581/—、pr6_sq .857/.739/.600（H-SQ2 ✗）；diversity top5/ttr pr6_sq .014/…。审计结论：调节变量=人格-语域兼容性，同一机制 p1 0.250、p2/p3 1.000（澜"主动确认与复述重要细节"使人格相容，林深"绝不啰嗦"被判 drift）；按人格分报必须是标准报告单元。时序证据：出厂即锁定非渐进劣化，early 段已低于 pr5（.857 vs .959），污染在 fade 前已就位（pr5 套语扩散 09:16–09:24，fade 09:54）。审计③（pr5 self 时代分布）未获支持，子串匹配法不可靠（短句误配），需换 atom-ID 埋点复核。套语密度 p1 8.8‰/8.4‰、诗意标记 1.1‰/1.4‰，与判 drift 的 8.2‰ 同档，而 pre-fade 自产套语仅 1.6–3.3‰，judge 放行重度仪式语发言，构念效度需补丁。失败分支：p1 仍塌→清洁自我可见性不敌实时社会压力（仍收 44–55k 他者流量）→解耦臂提前上位；p2/p3 反降→锚定切片与该人格近期发展冲突，回判读。
