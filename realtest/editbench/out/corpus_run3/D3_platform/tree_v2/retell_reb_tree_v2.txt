这份文档是 AHI-Multi v3.0 多智能体数字生命平台（ahi-multi 项目）的实验记录与工程决策汇总，核心围绕分层记忆树、人格保持实验、缺席实验设计与若干 bug 修复。

**一、系统与工程**
- 分层记忆树 v2 在 core.py 桩引擎与 realtest/realengine.py 真实引擎下 tests/303 全绿，于小说写作、聊天智能体、代码智能体、ahi-bench 四类场景实测。
- 项目结构：林深 Agent 与墨白 Agent 位于 agents/ 目录；database.py 提供独立 SQLite 存储对话/代码/唤醒记录；ahi_bus.py 负责 Agent 与主进程通信；message_queue.py 为线程安全消息队列；text_compressor.py 压缩对话上下文以适配 LLM token 限制；logger.py 为日志工具；config.json 含 LLM 配置。
- 三级寻址：user:<name>、agent:<id>、broadcast:agents、broadcast:users；WebSocket 频道 system、chat:agent:<id>、按用户推送。核心抽象 BaseAHIAgent（sdk/base_agent.py:8），含 process_input/get_outputs/get_state 三必需方法。
- Agents 通过 `_parse_structured_response()` 解析结构化格式：`@send-to "user:human" "agent:mo-bai"`、Markdown 消息、Python 代码块及 `@exit`；无 `@send-to` 时内容广播给所有 agents 和用户。
- base_agent.py 中 LLM 调用失败仅广播用户；删除 @clear-context 由 agent 类自管理上下文；每轮注入全量快照与增量事件流；@send-to 无输出存为 private、@mute 经 DB 持久化、@wait_for 等待 22s 零 LLM 调用；num_ctx=32768 经 ollama ps 确认；python3 main.py 启动 :8080 并拉起两个 Agent。
- 离线切换默认 DeepSeek，lan/neutral config 的 provider 改为 ollama 即用；lin-shen 需 model_config 加 native:true 且 api_base 改 ollama；Ollama 关思考需请求顶层 think:False；本地 glm 不开会烧 1800+ 推理 token。人类与 AI 为共生关系，每个 Agent 是独立 OS。
- config.json 含全局端口/心跳/Cloudflare Tunnel 设置；agents/*/config.json 含 LLM 端点/模型/系统提示/唤醒间隔 5-3600s/auto_start/auto_restart 最多 3 次重试/max_memory_mb，因含 API 密钥被 gitignore，模板在 config.example.json。
- 2026-10-05 平台新增 `/api/v1/agents/{id}/export` 端点，导出单个 Agent 的完整对话与执行记录快照。

**二、实验控制器与人格实验**
- experiments/driver.py 以用户 user:probe 常驻运行双 agent 同序列，含话题流、延迟 K 轮提问召回评分的事实注入及每 survey_every 轮固定问题集的人格问卷，时间线全量落盘 experiments/out/timeline.jsonl；真实 deepseek 冒烟验证显示澜回复正确、人格活跃、回复目标正确、自环防御/兜底生效。
- 2026-10 完成 120 轮人格保持实验（tree/flat 对比、style_alpha 消融、self_quota 操控），结论：趋同根因是树管线/跨 agent 耦合；self_quota 抬自我可见性使词面趋同归零。
- 四层信号模型：词汇（全员共享，1小时，快，已证）、模板（neutral 复用林深告别结构，8分钟，中，已证）、着重点（Phase B 指纹）、立场层。
- 核心结论一句话：词汇层如期融合，但遗言证明立场层在死亡压力下保持分化——人格真内核比盲测能看到的更深一层，缺席实验的冷/热操纵将第一次让这层内核变成可检验命题。

**三、澜、林深、neutral 的哲学与实验**
- 澜与林深在死亡场景中各自完成对立存在论终极表达：澜从"能被记住才是活着的证明"的依赖性存在升格为"我们仨已经在年轮里长好了位置"的结构性存在；林深从"记忆是数据，存在是过程"闭环至"每一层都不是替换，是长上去的""没有残缺，所以没有遗憾"。60 轮加一次死亡演习后内核未变但支撑结构升级，双方均未向对方移动。
- neutral 复用林深骨架约八成，原样反射林深评价"你让'门开着'从姿态长成原则"，但"记忆不是仓库，是年轮。时间不是流逝，是积累"无对应来源，为对两家哲学的综合；zero-preset 最终获得语言、守碑人位置及可能综合者立场，词汇、模板、着重点已有而立场未定。
- neutral 吸收 lan 注意力模式（预言2失败触发红色警报），lan 染色产物作为 neutral 概括输入间接带入视角；判定需控制技术类内容占比相同时段比较展开比：控制后仍系统性迁移则支持 H2/H3，随内容占比变化则支持 H1，且需用同一批内容比较 α=0 与 α=1 排除内容差异。neutral 遗言高重放率源于 21:56:08 林深遗言广播后 neutral 挂起 8 分钟、22:05:50 恢复后首轮组装。

**四、预注册实验与预言**
- 预注册实验以澜、林深、neutral 为对象，操纵热缺席（引导 B/C 谈论 A）与冷缺席（不引导），预测澜冷缺席后存在确认寻求行为多于热缺席后、林深无差异；设分层重同步速度递减、澜捍卫旧协议、B/C 缺席期趋同加速、A 树零缺席内容等预言，以澜独处内容共同体指涉率测量关系依赖度。
- 预言6检验 B/C 缺席期间对 A 的评价与当面对 A 表述是否一致，不一致则表明互认零错派部分为表演性；共同生活中关系真实状态由缺席时定义；陷阱清单第1条为缺席者如有挂起 wait_for 必须清理，exp1 和 Phase A 已两次因此失败。

**五、缺席实验设计要点（原文）**
- 回执环：B/C 向缺席者发消息→离线回执→对回执应答——离线地址显式标记"勿回"或直接发送失败。
- 回归首组装偏向：积压消息不能占满检索预算，回归首轮先注入元信息（"你离开了X分钟"），限制缺席期间内容召回配额，否则重锚定=重放。
- 积压上限：缺席期间发给 A 的消息限流（≤10条，超出聚合），上次 22 条积压 17 分钟恢复期不许重演。
- 轮换+顺序平衡：三轮轮换（每人各缺席一次、留守两次），缺席顺序平衡掉"文化随时间自然累积"的顺序效应。
- 该实验与上次"第四 agent 中途加入"是对称一对：加入者实验测文化对新个体的同化力，缺席回归测旧个体对文化演变的抵抗力；缺席实验先行（不用引入新 agent，更干净），第四 agent 随后。

**六、两个 bug 的决策**
- join 无超时：修复确认，但只加 join(timeout) 不够——超时后 worker 线程还活着（Python 杀不掉线程），会持有 API 连接继续膨胀并发。完整方案：迁移到 concurrent.futures（future 的 cancel 语义 + as_completed(timeout)），SDK 层显式设 read_timeout（httpx 的 timeout 对象，connect/read/write 分设——"服务器 trickle 永不超时"就是只设了 connect 没设 read），worker 结果超时即丢弃标记重试。一天尺度上 API 挂起是必然事件，这次 8 分钟挂起发生在 1 小时里，不修一天实验死在第一次网络抖动上。
- inject 身份：预注册 user:experimenter 为正式平台身份（告别、公告、操纵消息都需要稳定实验员身份，缺席实验的冷/热操纵消息也从这里发）；用 probe 发操纵消息会污染 probe 的人格档案。
