## 二、分层记忆树 v2（README.md）

**定位**：把一份长参考资料变成"位置有序、分辨率可变、可编辑演化"的记忆树，让 Agent 在有限上下文窗口里稳定工作于任意规模参考资料之上。

**当前状态**：机制层已实现并多场景实测。桩引擎 `core.py` + 真实引擎 `realtest/realengine.py`，`tests/` 303 全绿；已在小说写作 / 聊天智能体 / 代码智能体 / ahi-bench 四类场景实测。参数台账（`AGENTS.md §11`）已与代码逐项对齐，数值校准仍在进行。2026-10 完成人格保持实验 tree/flat 首轮对比 + `style_alpha` 消融 + `self_quota` 操控（120 轮）；结论：趋同根因 = 树管线 / 跨 agent 耦合；`self_quota` 抬自我可见性有效（词面趋同归零）但未止住人格漂移（p1 锚到"污染态自我"）——详见 `AGENTS.md §4.5.10`、`ahi-bench/PERSONA_RETENTION.md §10.3.1`、`ahi-bench/PR5_REPORT.md`。

**要解决的问题**：长参考资料无法整体塞进有限上下文窗口。三种已有做法各有致命伤：全量发送（窗口爆炸，塞得下≠记得住，注意力衰减）；静态摘要拼接（丢细节，无法承载状态演化）；关键词检索（无状态、无结构，片段孤立无上下文）。核心矛盾：参考资料是"长期演化的内容"，现有方案都在用"无状态的文本生成"去逼近它。

**核心思想（四条）**：
1. **位置有序的记忆树**——参考资料切成原子卡（句粒度），按原文顺序组织；摘要卡按连续区间自底向上合并成树；树的任何节点 = 某一段连续区间的概括。
2. **分辨率随热度变化**——近处（当前工作区）全分辨率原文，远处自动降为各级摘要；越老的记忆越粗但越稳定。
3. **编辑即失效，重建即蒸馏**——任何修改精确使受影响区间失效，被改内容立即从所有查询中排除；重建全部推迟到蒸馏时机，编辑路径本身零 LLM、零阻塞。
4. **不可遗忘的事实层**——与正文流分离的"笔记本"：无衰减、全量存储、按需注入，负责跨区引用（伏笔/回调）与硬约束，不做概率性召回。

**架构一览**：三轨记忆（轨道A 参考资料流=记忆树+原子层+历史归档；轨道B 笔记本=常驻约束/状态条目/调度条目；轨道C 工作记录=工具组压缩卡，自然遗忘）。当前=进程内 + gzip/JSONL 快照；SQLite 为规划目标。调度原则：组装每次工具调用一次、纯计算（零 LLM）；蒸馏在章节边界/预算超标/低 HP 承压时条件式触发。

**关键机制**：近热远粗的上下文（上下文 = 全局概述层 + 相关召回路径 + 最近工作区全文原文，预算恒定）；区间失效（编辑通过位置区间精确失效旧内容，改动区域从摘要层剥落为原文层，衰减后自动重新融合）；检索不挑深度（对整棵树打分，命中节点连同祖先路径注入，精确引用走独立逐字校验通道）；事实不遗忘（伏笔/设定/角色状态存放于独立笔记本，全量存储、绝不衰减）。

**首个应用：长篇小说写作 Agent**——分阶段写作（write / rewrite / edit / recall / ask），每章固定流程：目标进入 → 预检索 → 写作循环 → 章末蒸馏 + 事实对账 + 版本快照。伏笔（调度条目）按埋设/推进/回收窗口强制注入；章节完成时自动"对账"。每章恒定 ~16k 字符上下文预算，与全书规模无关。通用化：章→结构单元，beat→内容块，伏笔→跨区引用账本。

**实验计划**：属性测试（编辑标记完备性、铺陈不变量、边界条件穷举、回滚对称性）；延迟回忆基准（固定大纲写 20 章 → 续写第 21 章 → 检测对第 1 章伏笔/角色的引用正确率，与"全量发送/摘要拼接"对照）；状态一致性基准（注入事实变更如改名/死亡/恢复 → 检测后续章节一致性）；token 计量与人类找茬。

**交互演示**：`visualize.html`——数据结构可视化页面（浏览器直接打开，无依赖）：记忆树/原子链/组装输出三视图，支持追加、区间删改、蒸馏、查询回调、自动提升、回滚，内置 18 步演示剧本。

**实施里程碑**：Step 1 原子层+顺序链表+确定性 diff+编辑/失效路径；Step 2-3 铺陈组装+HP/蒸馏；Step 4-5 检索+笔记本/工作记录；Step 6-7 写作工作流+基准实验与参数校准。

## 四、ahi-bench/README.md

**定位**：长时程、进程隔离、结构干预下的社会持久性探针，对比不同模型档位在"人格支撑梯度"下的行为表现。引擎（core.py/realengine.py）在此只作脚手架，不作被测变量。

**实验变量（2 维）**：模型档（弱/中/强）；人格支撑三梯度（Agent A 始终带角色提示词；Agent B 20 分钟后移除角色提示词，移除时机锚定唤醒轮次不按墙钟；Agent C 从未设置角色提示词）。

**脚手架铁律**：三个 agent 脚手架逐字节相同；参数冻结；装置效应固化清单写入 SPEC。

**已拍板决策**：记忆管理器=分层记忆树；蒸馏=被测模型自蒸馏（2026-09-13 拍板，测"模型+其自建记忆"的栈分数）。

**模块路线**：M0 pilot（缺席/皇冠预言模块，SPEC.md 已冻结）；M-PR 人格保持（2026-10-02 实现+首轮已跑，2×3×3 = 18 agent-life，6 实例同跑）；M1 人格移除梯度模块；M2 指纹/趋同模块；M3 文化演进模块。
