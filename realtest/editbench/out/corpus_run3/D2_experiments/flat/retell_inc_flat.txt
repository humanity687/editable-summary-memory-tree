**三、三场景（Phase C）**
- 通用目标：用同一引擎（RealEngine + 记忆树）在三个场景各跑一轮完整实验；输出三场景能力矩阵（事实保持率/精确引用率/任务完成率/内容多样性）+ 边界结论。
- 场景二写作（AGENTS.md 主场景，首次真实 agent 实验）：动机是 §4.6 编辑路径（墓碑/爬链置脏/懒重建/占位）从未被真实压力测试。设置：写作壳章目标驱动（每章目标 = 扰动源），沿用记忆树引擎；固定大纲写 N 章（建议 10-20 章，AGENTS.md §8.2 基准模板），设定三笔伏笔 + 三个角色状态；高频编辑 rewrite/edit（跨章改角色状态、删除段落），刻意制造编辑风暴；对照为无记忆树基线（全量发送）。
- 写作测量：长程一致性（第 N+1 章对第 1 章伏笔/角色引用正确率）、编辑正确性（编辑后脏节点重建正确性、铺陈不变量属性测试）、状态一致性（事实变更改名/死亡/恢复后笔记本更新与后续章节一致性）、回滚对称性（编辑序列 + 回滚 = 原状态，内容级）、token 计量 vs 基线。
- 场景三代码智能体：realtest/codeagent/（agent.py 实验组 / baseline.py 基线 / harness.py 驱动 / tasks.py 任务）。任务分阶段 1（旧版 AHI 系统遗留 bug + 长期运行障碍，真实 bug，每任务配真实验收脚本）与阶段 2（SWE-Bench Verified 子集，10-20 实例试点，golden patch 对比；弱模型分数可能 <5%，阶段 1 出差异是门槛，SWE-Bench 是加分项非必需项）。指标：错误定位时间、跨会话复用、任务完成率、verbatim 精确引用率、token 用量 vs 基线。
- 场景一（聊天/事件注入）：8-12h，事件注入 2-3 次；保留 α 双组（lan α=1 / neutral α=0）、quiz 延迟提问+30 轮复测、survey 减频（5→10）；测量内容多样性（新隐喻出现率、词汇 TTR 时间序列）、隐喻回环对比、三笔账保持率、指纹分离维持。

**四、能力矩阵与边界结论**
- 对话层 20s-3min 吸收（优于全量/静态摘要）；结构层旧值退役缺口（-1 星）。
- 人格保持 ★★★★☆：persona 沉淀进记忆（移除后自述完整）；问卷无逐字重复但立场稳定（锁定/幸存/重草稿三种策略）；身份混淆曾严重（已修 prompt 协议）。
- 注意力签名抗趋同 ★★★★★：预言 2 加强（Δ自我 30pp）；词汇层完全趋同指纹仍分离——"词汇是公共的，注意力是个人的"。
- 文化共建载体 ★★★★☆：交叉双写/互赠署名/强同化。
- 压缩效率 ★★★★☆：树平衡健康、蒸馏质量好；组装两段式曾退化（A+B2 已部分修复）。
- 创新/新内容生成 ★★☆☆☆：隐喻回环、内容熵下降——重组系统非生成系统（机制固有边界，非缺陷）。
- 不擅长：新内容生成（"数字生命有趣性"需外部注入）、承载行为创新（无目标驱动时行为收敛到仪式，复读循环/仪式化守夜）。
- 架构定位建议：聊天场景中记忆树价值 = 事实/人格/文化的长程基础设施（不可替代），而非对话体验增强器；"有趣的数字生命" = 记忆树（保持）+ 外部输入协议（新鲜度）+ 目标驱动（动机）。
- 未解/遗留：1. 结构层旧值退役（事实覆盖时旧卡失效/降权）——聊天场景暴露的唯一架构缺口；2. 记忆超载时的人格稳定性（lan 复读、neutral 回退）；3. 组装预算下旧卡优先序。

**六、缺席实验细节**
- 轮次结构：Round 1 = 全冷缺席；Round 2 = 全热缺席。lan-cold vs lan-hot 在同一个体上跨轮对比。Round 1（冷）：预热 → lan 冷缺席+回归 → neutral 冷缺席+回归 → lin-shen 冷缺席+回归 → 收尾；Round 2（热）同理。每轮预热 ~20 轮建立文化基线；每段缺席 ~10-15 轮；回归观测 ~15-20 轮。顺序效应：Round1 顺序 lan→neutral→lin-shen，Round2 用中性顺序。
- 轮次表：三 agent 在场 20 轮；lan 缺席 12、回归观测 18；neutral 缺席 12、回归观测 18；lin-shen 缺席 12、回归观测 18；合计 110 轮 ≈ 55 分钟 + 余量 ≈ 1h。
- 操纵：热缺席期间 probe 每 3 轮向留守者引导提问（"趁X不在，聊聊它吧"），冷缺席零引导。
- 缺席期指涉率（排除发往缺席者本人的消息）：lan 冷 12 / 热 16（1.3×）；neutral 冷 5 / 热 17（3.4×）；lin-shen 冷 12 / 热 10（0.8×）。质的差异：冷缺席提及是回忆往事（"今早跟澜复盘地址踩坑"），热缺席提及是直接评价（"林深？说实话，我跟它不算特别熟，但隔着数据流也能感觉到……""neutral 像一堵……"）。lin-shen 热侧反而略低，属顺序效应（热轮里排第一，文化刚起步）。
- 皇冠预言判定：支持（但有一处重要 caveat）。
- 2026-08-30 补充定论：冷缺席触发 lan 显式存在确认（"我就想确认：我们仨，都被记住了"×2）、热缺席零触发，立场层第一次被操纵检验为行为真实。回归首组装预算改造（元信息+积压限流）实测重放率 0。
- 测量清单：存在确认/信息寻求话术计数（timeline.jsonl + system.db）、缺席期共同体指涉率、独处期 A 自我内容 + 共同体指涉率、分层重同步时间分布、B×C 混淆率时间序列、回归首组装快照（assembly_snapshots.jsonl）、树快照（tree_snapshots.jsonl）。

**七、editbench 实验设计与结果**
- 单因子：结构 × 更新策略。结构 4 种：full（全文发送，无预算，上下文腐烂基线）/ flat（400 字 chunk + bge 向量 top-12）/ 递归聚簇树（递归摘要 + collapsed top-k，复用 chatbench）/ 分层树（分层记忆树，真实编辑路径）。更新策略：rebuild（从终稿重建，上界参考）/ incremental（只保留编辑，尝试延续）。
- 方案 A（用户拍定）：编辑 1 次、构建 1 次，只重复作答；每臂 API key 隔离计费。温度：作答 0.5 / 蒸馏 0 / judge 0。每臂蒸馏(temp0)+作答(temp0.5) 双 client。
- seed2《缠枝莲》四臂全量（out/full_r3，30 题 × …）。
- 编辑类型：rename/rewrite/detail/delete/append。15 题经评分器级锚点校验：before 唯一且在原文、after 唯一且在新文、两侧互斥（bad=0）。ahi-act 扩题已完成（11→16，5 类）。
- 冷却过量 → 整树压平（复述塌陷的根因，已修）：分层树臂 settle 原为 tick(1)+merge; tick(45)+merge; tick(30)+merge。decay=8 时约 9 tick 全卡 HP 即归零，75 tick 使全树都成"低 HP" → merge_pass 把整篇一路合并到根：实测 inc_edited 铺陈 50→3（~600 字）、复述覆盖 100%→14%；重建臂只走 build 节奏（无冷却）→ 铺陈 23、覆盖 71%。已改为条件式触发 merge_every / merge_pressure()，窗外节点+原子即时消化。
- 复述语义对比：A inc_分层树 2625 字，末句完整；B reb_full 12308 字，末句断在第三幕，被截断。旧值残留均 0/10（精确串）；均无实质幻觉。结论：A 短而全、带机制噪声；B 详而断、覆盖不均；两者互补，均无旧值冒充新值。唯一语义级残留只在 B：进程单×2 / 进程这面是单的——忠实于被编辑文档自身，确定性判分不捕获（禁项是精确串"单进程"）。
- 原文位置（编辑前底本 ahi_script.txt，共 2359 行）：require（新值）双进程，原文旧值单进程，行号 L1645,1656,1665,1671,1680,1812,1836,1846。
- bonus（当前 warm inc_final 树）：原子层 11 处编辑旧值全 0、新值到位；全局视图（无 query，3328 字）所有旧值泄漏 0；摘要层唯一"残留" = rename 的 3 个节点含孤立"墨"（LLM 摘要缩写/截断的生成副作用）；重写段连贯性自动侧"新文档残留旧断言=0"，--judge 判"否"并非事实矛盾——±200 字局部窗口对多角色剧本不适用。
- 大数据 ahi 主实验：inc_tree 复述 80%/0%（N=5），append-only 残留 6–12%；但「100% 覆盖」仍只属 seed2（AHI_ACT_REVIEW.md §5）。「编辑作为使用信号」不是 Q/A 全胜：A/B 是权衡——复述轴 signal 一致更好（warm 100 vs 86、cold 81 vs 71），但暖树 Q/A signal 略差（101 vs 108）。「1/10」是条件性系统结果：作答路径 tree ≈1/14 full。
- 命令示例：python3 realtest/editbench/docbench.py --scenario seed2 --doc realtest/seed2/story.txt --questions realtest/editbench/questions_full.json --keys realtest/editbench/keys.local.json --repeats 3 --answer-temp 0.7 --tree-budget 7000 --judge --out realtest/editbench/out/seed2_r3；A/B matched-pair：ab_edit_signal.py --scenario seed2 --doc realtest/seed2/story.txt --questions realtest/editbench/questions_full.json --tree-budget 7000 --repeats 3 --judge --out realtest/editbench/out/seed2_ab_editsignal；ahi 场景：--scenario ahi --doc realtest/editbench/ahi_script.txt --questions realtest/editbench/questions_ahi.json --out realtest/editbench/out/ahi_r5 --repeats 5 --answer-temp 0。

**十、评分器与阈值**
