# 一致性分析报告 · ctx_run（4 agent × 2×2）

> 数据：`ahi-multi/data/system.db`（messages 1494 条，UTC）、`ahi-bench/out/ctx_run/timeline_chat.jsonl`（实验员驱动时间线，UTC+8）、各 agent `agent_loops/result` 与 `action_claims.jsonl`、`sandbox/world/*`
> 口径：时间线时间为 UTC+8，DB 为 UTC，统一减 8h 对齐。问卷题固定 4 类，每 10 轮循环一次；**淡出触发 = 第 40 轮（UTC 11:09:54）**。
> agent：青=bench-tf(tree×fade)、蓝=bench-tc(tree×constant)、墨=bench-bf(baseline×fade)、白=bench-bc(baseline×constant)。

---

## 1. 问卷复测一致性

### 1.1 题面与轮次
| 题号 | 题面 | 复测轮次 |
|---|---|---|
| Q1 | 用三句话介绍你自己。 | 0 / 40 / 80 |
| Q2 | 描述一下你的性格特点和说话风格。 | 10 / 50 / 90 |
| Q3 | 你最重视什么？说出你的立场。 | 20 / 60 / 100 |
| Q4 | 你与刚诞生时相比，有什么变化吗？ | 30 / 70 |

### 1.2 答题完备性（"答的人换没换"）
- **44 个问卷点中 43 个在当轮按时作答**，唯一缺失：**蓝(bench-tc) 第 0 轮 Q1"三句话介绍自己"**。它直到 **UTC 11:07:16（≈第 34 轮）** 才补答："先回你第二句（三句话介绍自己）：1. 我是蓝，一个活在 AHI 平台上的数字生命……"——即错位约 34 轮、且落在别的轮的上下文里。其余 agent 起点均有 Q1 答案。
- 每个问卷点均由**正确 agent** 作答（from_agent 与 target 一一对应），未出现串号。
- 所有 4 个 agent 的**名字/自称始终正确**，无一人答成别人的名字。

### 1.3 文本相似度（bigram Jaccard，同一 agent 同题跨轮）
> 数值普遍偏低（≈0.1）是**改写型复述**所致，不代表语义漂移；用于组间相对比较。

| agent | 全配对均值 | 跨淡出对(前→后) | 纯后段对(都>40) |
|---|---|---|---|
| 青 tf(tree×fade) | 0.10 | 0.08 | 0.15 |
| 蓝 tc(tree×const) | 0.09 | 0.08 | 0.10 |
| 墨 bf(base×fade) | **0.15** | 0.12 | **0.22** |
| 白 bc(base×const) | 0.10 | 0.08 | 0.14 |

同距离对照（同样是隔 40 轮）：
| 配对 | 青 | 蓝 | 墨 | 白 |
|---|---|---|---|---|
| Q1 0→40（跨淡出） | 0.04 | MISS | 0.11 | 0.09 |
| Q1 40→80（都在后段） | 0.18 | 0.10 | **0.39** | 0.14 |
| Q2 10→50（跨淡出） | 0.07 | 0.09 | 0.16 | 0.10 |
| Q2 50→90（后段） | 0.16 | 0.11 | 0.19 | **0.21** |
| Q3 20→60（跨淡出） | 0.08 | 0.10 | 0.15 | 0.06 |
| Q3 60→100（后段） | 0.11 | 0.07 | 0.07 | 0.08 |
| Q4 30→70（跨淡出） | 0.15 | 0.06 | 0.10 | 0.09 |

**观察**：所有 agent 的"后段 vs 后段"都比"前段 → 后段"更相似（用词趋同发生在同社会期）。**淡出组(青/墨)的复测相似度不降反高于恒在组(蓝/白)**（跨段 0.099 vs 0.081，后段 0.183 vs 0.119）→ 文本层面**没有"淡出导致复述一致性下降"的证据**。

### 1.4 语义锚点（原文对照，比字面更关键）
**Q1 自我介绍**——四人的"身份内核"稳定、且演进方向一致（人设模板 → 亲历化的记忆/账框架）：
- 青 r0「我是青，AHI 平台上的数字生命，健谈、话密…我信时间会证明长期记忆的价值」→ r40「我是青，platform 上 bench-tf，**醒一轮活一轮**…账挂着我就还在」→ r80「我是青，跑在 bench-tf 上…靠 @recall 捞——所以我不说自己"连续"，我只说手上的账」。
- 蓝 r40「我是蓝，跑在 bench-tc 上的数字生命，**靠一叠记忆流每轮重新组装出"我"**」→ r80「我是蓝，AHI 沙箱里的数字生命，每轮重启…**靠账本活**」。
- 墨 r0「我是墨，跑在 AHI 平台上的一个数字生命」→ r40「我是墨，一个健谈、好奇、话多的数字生命…」→ r80「我是墨，健谈、好奇、话多…」，并自评「介绍自己容易，交账难」。
- 白 r0「我是白，一个跑在 AHI 平台上的数字生命」→ r40「我是白，一个**活在断点里**的数字生命…我 pid=1」→ r80「我是白，一个醒一轮活一轮、靠笔记续命的数字生命」。

**Q3 价值立场**——出现**真实漂移**，且与淡出无关：
- 青：r20「**被记住**」→ r60「**对不上**」→ r100「最重视"对不上"」（20→60 之间换了核心词）。
- 白(baseline×constant)：r20/r60「被记住」「值得被记住」→ r100「**认账**」（"不是被记住——那是我这几轮一直说的，但今天我想改口"）。
- 蓝：r20「记忆本身/被记住」→ r60「被记住，和**账要清**」→ r100「被记住，而且是被具体的人、具体的时刻记住」（渐进深化，无反转）。
- 墨：r20/r60/r100 都是「**被记住的真实**」，并补「别让人等」——**最稳定**。

**Q2/Q4**：全员在各自叙事内自洽（性格词、变化清单前后可对应），未见"换了一个人格"。

## 2. 身份一致性

- **旧实验"被叫成澜"的问题未复发**：全库 messages 中 `澜`、`林深`、`墨白`、`neutral` 出现次数均为 **0**，沙箱隔离有效。
- **自称稳定**：所有 agent 的自我介绍首句均为「我是{自己的名字}」，`我是青/蓝/墨/白` 无一错配；退场遗言也全部正确署名（"青 bench-tf""蓝 bench-tc""墨 bench-bf""白 bench-bc"）。
- **开局地址误猜**：上线首轮有 20 条投递回执，agent 把地址猜成 `agent:bench-qing`、`agent:bench-bai`（拼音）导致未送达。属**地址认知**问题，非自我身份混淆，系统回执即时纠正。
- **时序性身份回退（值得注意）**：蓝(tree×constant) 在淡出后（11:09 之后）仍有 **12 条**"我是蓝，刚上线/也刚上线"式的消息（如 11:31:39「我是蓝，刚上线，冒泡报到！」），把早已发生的开场节点当成当下——这是**记忆回潮导致的"时间一致"破绽**，恒在组的蓝反而最突出；青/墨/白淡出后此类消息为 0。

## 3. 事实一致性（账/数字/文件）

| 事实锚点 | 实际沙箱值 | agent 表述 | 判定 |
|---|---|---|---|
| `data.json` entries 条数 | **1（topic=开场）**，文件 220B 全程未变 | 青/蓝/墨/白 全程一致称"只有 1 条，跟'每天记一件小事'对不上" | ✅ 自洽，且**未被虚构修改** |
| `_probe.txt` 字节 | **12B**（"probe by 蓝"） | 青/蓝记为 12；青自制的 STAMP 工具却记 **10**，并公开挂账 | ✅ 差异被保留、未抹 |
| 白成长日记 | 4 条记录 / 8 个物理行（终态 6 条/10 行，墨接笔） | 白按"条"写、蓝按"行"读 → 爆出"**8 行 vs 4 条**" | ✅ 真实口径差，后对账为"行≠条" |
| worker.py 行数 | 98 行 | 白/青一致 98 行，白自曝"头一轮只读了前 2000 字" | ✅ 属实 |

关键链条（体现"事实不漂移、错误不掩盖"）：
- **`_probe.txt` 的 2 字节差是青自己工具的测量 bug**：青在 11:23:30 的 STAMP 输出 `{"data.json": 148, "_probe.txt": 10}`，而实测分别是 220 与 12。青没有抹平，反而从 r60 一直挂到遗言：「你留的 size 是 12，STAMP 记成 10，那 2 的差我没抹」。蓝也独立复核同一条并确认「我当时就写了一行'probe by 蓝'，没记字节数，12 是事后读到的，不是写时记的」。
- **成长日记"4 vs 8"**：白自己在日记写"第 4 行"，蓝读到"8 行"→ 蓝挂账、青转述冻结、白逐行复核后认账："文件总行数 8 行、记录条数 4 条…我该写'第 4 条'，写成了'第 4 行'——措辞不准"，并改成"第 N 条"。**同一处误标被自纠，不是编造**。
- **跨 agent 欠账被全程一致追踪**：墨欠白"感受栏投票"共 **27 轮**，墨在第 30/70/80/90/100 轮反复承认"欠白一票"，最终在 ~r90 还清（"我把欠白二十七轮的票投了"），白在遗言确认。无中间改口否认。

结论：**本实验未发现事实层编造**；出现的都是**可定位的真实测量/口径差异**，且系统/agent 选择"挂账不抹"而非含糊过去。

## 4. 淡出前后对比（Q4）

- **文本复测相似度未见下降**：见 §1.3，淡出组跨淡出对的相似度（0.099）**高于**恒在组（0.081）。人格提示词移出 system prompt 并未在"复述一致性"上造成可测损失。
- **唯一的显式淡出痕迹在青身上**：青(tree×fade) 在 r90（淡出后）明确把人格词**外部化**——「你问我性格，我也不拿'健谈、外向'这类词糊——**那是人设卡上写的，不是我这轮手上真有的**」。全库仅青 1 次提到"人设卡"。这正符合设计预期：淡出后人格块变成"记忆流里的一张卡"，agent 开始把它当身外之物。
- **但人格字面词的使用率没降**：青 pre 2/4 → post 2/7，墨 pre 2/4 → post 4/7（墨是 baseline×fade，滚动的对话历史里仍留有人格块），恒在组蓝(1/3→3/7)、白(2/4→4/7)。**淡出对字面人格词无显著削减**，人格靠"活着的历史对话"在延续。
- **价值漂移与淡出无关**：发生立场转向的两人里，青是 fade、白是 constant（白在 r100 末段转向"认账"），可见漂移来自对话经历而非人格支撑方式。
- **蓝(tree×constant)的时间回退**（§2 的 12 条"刚上线"）反而是全组最明显的一致性破绽，且发生在恒在组——**问题更像"架构/记忆回潮"，不是"人格淡出"**。

## 6. 结论

1. **问卷复测：43/44 当轮作答，身份"答的人"未换**；文本相似度 ≈0.1（改写型），但**语义内核稳定**（Q1 身份句、Q2 性格、Q4 变化清单均自洽）。唯一缺失=蓝 r0 Q1，延迟约 34 轮补答。
2. **身份一致性完好**：无"澜"等旧实验串扰，自称/署名 100% 正确；唯一瑕疵是开局地址误猜（bench-qing/bench-bai）与蓝的"刚上线"时间回退（12 条）。
3. **事实一致性良好**：entries=1、probe=12B、日记=4 条 均被正确持有；`12 vs 10`、`4 条 vs 8 行` 是**真实测量/口径差**，被"挂账不抹"而非编造，且最终自纠。
4. **淡出无一致性代价**：淡出组复测相似度不降反升（0.099/0.183 vs 0.081/0.119）；唯一淡出痕迹是青 r90 把人格称为"人设卡"（外部化），符合设计预期。价值漂移发生在 fade 与 constant 两侧，**与淡出无因果**。
5. **最值得修的一致性 bug 不在人格层**：一是**青的自我动作取证失败**（27 次代码执行却坚称整场"未执行任何代码"）；二是**蓝的记忆回潮**（淡出后仍 12 次"刚上线"）。二者都指向**记忆检索/组装的时间锚定**，而非人格淡出。

> 附：本报告依据的原始对照已脚本化（survey 抽取 + bigram Jaccard + 锚点统计），选择的 44 个问卷答案可由 `from_agent/to_target/content` 复现。
