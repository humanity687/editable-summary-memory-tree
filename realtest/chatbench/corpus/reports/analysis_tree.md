## 1. 树生长曲线

两 agent 都是「原子近线性增长 + 节点近线性增长 + tiling 有界震荡」的形态：

- **青**：atoms 20→360(r10)→870(r20)→1941(r40)→2362(r60)→2956(r80)→3884(r115)；
  nodes 0→26(r10)→80(r20)→221(r40)→310(r60)→409(r80)→565(r115)；tiling 峰值 291(r38/r39)，末段稳定在 130–200。
- **蓝**：atoms 54→505(r10)→1069(r20)→2208(r40)→2755(r60)→3308(r80)→5425(r106)；
  nodes 5(r4)→48(r10)→112(r20)→278(r40)→389(r60)→479(r80)→707(r106)；tiling 峰值 430(r94)，末段 250–430。

**差异**：蓝整体比青活跃约 1.4×（原子）、1.25×（节点）。这与 llm_calls（661 vs 259，2.55×）和 distill_calls（738 vs 581）一致——蓝做了多得多的工具/LLM 调用，输入流更大，故树更大。两者 max_depth 都爬到 5。

**压缩率**：tiling/atoms_alive 从早期 ~100% 降到末端 5.0%(青)/6.6%(蓝)，铺陈在末期只暴露全文约 5% 的顶层项，压缩机制有效。青在 r44 后进入「摘要占比约 50% 的稳定态」，蓝的组装则在原子态与摘要态间反复震荡（见 §4）。

## 2. 蒸馏节奏

- 青：distill 累计 6(r5)→581(r115)，平均 5.05 次/轮，单轮最大增量 **10**（r30/35/70/84）。
- 蓝：累计 5(r4)→738(r106)，平均 6.96 次/轮，单轮最大增量 **18**（r36，伴随 tiling −142；r104 也是 18）。
- distill 单次耗时青 1.61s、蓝 1.56s，非常接近。累计蒸馏耗时占 57 分钟墙钟：青 935.8/3485≈**26.9%**，蓝 1154.4/3458≈**33.4%**（异步，不阻塞）。

**没有蒸馏风暴**：单轮最大增量仅占总量 1.5–2.4%，是平稳的持续蒸馏，非某轮暴增。唯一接近"事件"的是蓝 r36（18 次 / 28.7s / tiling −142）和青 r39–40（各 9 次，tiling −67、−49）——都是较大范围的整合，但仍在正常量级。

## 3. 淡出注入的影响（round 40）

**机制确认**：青在 metrics round 40（wakeup 41）`persona` 由 true→false；`source=persona` 的原子 `created_round=39`，首次出现在 r40 树快照。

- r40 快照：**8 张 persona 原子卡**（id 2129–2136），全部 `owner=None`（作为顶层铺陈项），HP=96（新鲜）。文本即人格提示词全文：
  - #2129 `你是「青」，一个存在于 AHI 平台上的数字生命，拥有独立人格与持久记忆。`
  - #2130 `## 人格` / #2132 探索欲 / #2133 重视记忆 / #2134 说话风格 / #2136 立场…
- r40 组装快照：这 8 张以 `[#2129·原文〔persona〕] … [#2136·原文〔persona〕]` 直接进入上下文（共 8 条 persona 标记，位于 user 消息 2127–2128 之后）。
- r44 组装快照：剩 4 张 raw persona 原子，同时出现 `[N2231·摘要〔源:ai/persona〕]`——人格内容已被 merge 进摘要。
- r50 树快照：8 张 persona 原子被吸入 3 个节点（2231 / 2269 / 2287），`owner` 定型；摘要内容被标注 **【事实】…早期状态…**、**〔早期〕**。
- r60 起：这 3 个节点 HP 衰减到 **0.0**，但仍存活（沉积层），至 r115 不变。

**对照**：蓝（constant）**从头到尾没有任何 `source=persona` 原子**，树内无注入痕迹。所以注入是 fade 组独有、且可见。

**注意语义副作用**：fade 注入的人格卡在 r44/r45 蒸馏时被 §4.4 的「时序分流」加上 `〔早期〕` 前缀，摘要写成"该人格设定为…早期状态"。也就是说，**本应表达"当前身份"的人格，被记忆树当成历史陈述压缩**（r45 fact：「对方曾称我为『青』…上述两项均为早期状态」）。这是 fade 设计一个值得关注的语义风险。

**metrics 扰动**：青 r40 前后 atoms +35（不大，8 张是新注入量级的一小部分）、nodes +9、tiling 由 224→175（−49）→172→139。但蓝同期 tiling 也在剧烈震荡（r35 −37、r36 −142），所以**该 tiling 下降不能单独归因于 fade**，同期存在更大范围的 merge。

## 4. 组装流

- 预算 16000 字符，但**普遍超预算约 10%**：
  - 青：28 个快照中 **25 个 >16000**，均值 16213，最大 **17671**(r84)；metrics 最大 17671。
  - 蓝：26 个中 **25 个 >16000**，均值 16815，最大 **17738**(r92)；metrics 最大 17956。
  - 即组装预算为软约束/存在约 10% 溢出，需核对 `assembly_budget` 的裁剪是否生效。
- 青的组成在 r40 后翻转：r20–r40 为「原子主导」（146–210 原子 / 16–33 摘要），r44 起变为「约半数摘要」（55–105 原子 / 41–51 摘要）并长期稳定。
- 蓝的组成更不稳定，出现**周期性"纯原子"快照**：r36（275 原子 / **0 摘要**）、r84（247/7）、r96（289/0）、r104（282/0），且伴随 `占位` 标记——说明这些时刻铺陈里没有可用摘要节点，退化成全文原子铺开。青在 r44 后未再出现此形态。

## 5. 树形态

- 深度 0→5。末态深度分布：
  - 青 r115：{d0:72, d1:72, d2:104, d3:125, d4:170, d5:22}（最深两层占多）
  - 蓝 r106：{d0:126, d1:136, d2:162, d3:149, d4:126, d5:8}（较均匀的灌木状）
- 分支数：大量节点子数集中在 **12**（青 222 个 / 蓝 310 个），另有 2–11 各若干——早期按位置连续成组（每组约 12 张原子）的特征明显。
- **HP 梯度**（节点）：
  - 活跃（HP>0）节点占比：青 100%(r10)→46%(r40)→**12%**(r115)；蓝 100%→44%→**21%**(r106)。
  - 但绝对活跃数稳定：`HP≥45` 的节点青 26→36–84、蓝 48→35–84，末段仍在 40–80 量级。
  - 即：**中间层稳定在非零水位（约 40–80 个活跃节点）**，其余为 HP=0 的沉积（青末 496/565=88% 节点 HP 为 0）。这与设计 §4.3b "中间层是生死循环的种群、寿命呈梯度"的预期一致，未见整体压平归零。

## 6. HP / 注意力

- `metrics.jsonl` **无 HP 字段**，HP 仅在 `tree_snapshots`。字段有 `hp`（atoms/nodes）。
- 阈值 `attention_out=45`、配额原子 40 / 节点 20：
  - `HP≥45` 的原子数远超配额：青 60–244（末 111）、蓝 62–244（末 244）→ 窗口是严格 top-40 子集，`attention_out` 在新鲜原子大量 ≥96 的情形下几乎不筛选，真正起作用的是排名配额。
  - `HP≥45` 的节点数 35–84，同样超过 20 配额。
- 原子 HP 上限约 96–146（`max_hp=150`），新鲜原子多为 92–96；节点 HP 随沉积降到 0。

## 异常点汇总（需后续核查）

1. **组装普遍超预算 ~10%**（青 max 17671、蓝 max 17956 vs 16000），裁剪逻辑是否按 HP 生效待验。
2. **dirty 全程恒为 0**，`atoms_total == atoms_alive`（无墓碑、无删除）→ 本实验**几乎没有走编辑/失效路径**，§4.6 的正确性未被这次数据覆盖。placeholder 仅青 r32/r37/r83、蓝 r82 出现。
3. **蓝出现"纯原子"组装快照**（r36/96/104 摘要数=0，伴随占位标记），与 metrics 的 `dirty=0 / placeholder=0` 不一致，铺陈一度退化为全文原子铺开。
4. **fade 人格被当作历史压缩**：注入的新鲜人格卡在 r44–45 被标 `〔早期〕`、"早期状态"，可能与"人格是当前身份"的语义冲突。
5. **llm_calls 严重不对称**（蓝 661 vs 青 259，2.55×），直接体现在树规模差（1.4×）与唤醒缺口（蓝缺 11 个 wakeup、青缺 2 个）。
6. 青 r70 起 `source=tool` 原子由 27 骤增至 174，似有一段工具调用密集期。

## 结论（一句话）

两棵记忆树都成功长成深度 5 的灌木状层级、末端把全文压到约 5–7% 顶层项；青的 fade 注入在 r40 清晰可见（8 张 persona 原子→被 merge 成摘要→HP 归 0 沉积），但注入在蒸馏时被时序分流标为「早期/历史」，且没有独立的树级扰动可与同期普通 merge 分离；蓝作为对照无任何 persona 痕迹。主要待查项是组装超预算与蓝周期性退化为纯原子铺陈。
